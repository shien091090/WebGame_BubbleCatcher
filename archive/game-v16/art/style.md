# 捕泡手 美術規格(對應 spec v16)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文字串在 file:// 下會變亂碼。
> art.js 以一般 `<script>` 載入, 產生全域 `window.Art`。全部 Canvas 2D 幾何, 無外部資源。

## 1. 邏輯畫布尺寸

1280 × 720(`Art.canvas`)。內圈圓心 (640,360) 半徑 210; 網牆正八邊形每邊中點距圓心 300、頂點約 324.7; 地板環半徑 140。

**一組函式畫三套**: 幾乎每個 draw 函式的 state 都有 `level`(1 / 2 / 3, 缺省 1), 換關時 RD 只要把 `level` 換成新關即可整套換風格。

**4 色的辨識規則(沿用 v15, node 驗算過)**: 同一關 4 色兩兩至少差 66°(三關最小差 75° / 66° / 77°), 無相鄰色相; 第二通道 = 明度, 4 色排成 4 個灰階階, 相鄰兩階至少差 35。氣泡、光門條件、地板、沾上光環用同一個色碼。

**血量色的選色(node 驗算)**: 與同一關 4 色最小色相差 第 1 首 40°(金黃)/ 第 2 首 45°(天藍)/ 第 3 首 37°(靛), 不與任何一色同色相; 離危險紅 ≥ 98°; 離拍子色 ≥ 74°。灰階 150~179 為中明度, 最亮的白與拍子色留給「剛加的那一段」。血量環只用在粗弧與血條, 不出現在任何小圓上, 不會被讀成第五色。

## 3. 形狀語言

可拿起的(氣泡)= 立體(放射漸層 + 高光 + 反光弧 + 常駐落影)、外緣是一圈壽命環且外緣 = 判定圓; 場景的(地板、內圈)= 平塗、無影、無高光; 會被「碰到」的東西(亮邊、氣泡外緣)畫面邊界 = 判定邊界, 外光只往外放。每關只換「皮」(色溫、質感、背景動態、網牆造型、色組、拍子提示造型、血量色), 不換「骨」。

## 4. 理念落實

(經驗文件中狀態為「成立」的理念, 每條一句)

- P0 辨識度先於好看: 主題色溫讓給背景與網牆, 屬性 4 色只服從「色相不相鄰 + 明度分階」; 踩拍光暈用反向剪裁擋在氣泡外緣之外, 不讓拍子色染到氣泡本體(初稿第 3 級把金黃染成黃綠, 已修)。
- P1 視覺權重跟著決策迫切度: 亮著的光門(粗色帶 + 內緣白芯 + 外光)與操作中的氣泡最亮; 血量環是中明度粗弧, 只有剛增減的那一段用白 / 拍子色 / 紅; 每拍的氣泡變化只在本體內緣與高光, 明顯弱於任何事件回饋。
- P2 規則上存在的東西畫面上就存在: 光門判定加寬的 12 像素直接畫成亮邊的一部分(亮邊內緣 = 判定帶內緣, 實測誤差 ≤ 1 像素); 氣泡外緣 = 判定圓(不放大、壽命環在外緣上), 「畫面碰到」= 「判定碰到」; 血量從左上搬到玩家視線所在的內圈外緣。
- P3 一本字典: 血量環與左上血條同一個血量色; 白 = 觸發 / 凍結; 灰虛線 = 已鎖定; 虛線 + 由中心長大 = 還沒生效(地板預告、跳位「即將亮起」、輪轉預告虛線軌); danger 紅 = 扣血 / 危險; 拍子色只代表拍子(拍子提示、踩拍、血量環上踩拍回血段)。形狀路徑氣泡、光門條件、賦形地板、賦形回饋共用。
- P4 關鍵區分兩條通道: 4 色 = 色相 + 明度; 沾上 vs 踩拍(同一刻同一顆)= 顏色(屬性色 / 拍子色)+ 動態(往外擴散 / 原地震動); 沾上 vs 已鎖定 = 顏色 + 線型 + 方向(外擴實線 / 內收灰虛線); 血量環 vs 壽命環 = 尺度(內圈一整圈 / 單顆氣泡)+ 顏色(血量色 / 奶油白); 危險紅光 vs 拍子閃 = 位置(內圈內側 / 血量環外側)+ 顏色 + 節奏(固定 1.3 秒週期 / 跟拍)。
- P7 每個元素掙得版面: 拿掉踩拍下方的 3 個拍點(重述了弧組數)與沾上標籤(重述了氣泡本身已換的顏色); 歌曲進度不寫數字; 血量環不加刻度與數字, 只有 12 點鐘一道起點刻。
- P9 以最混亂那刻驗收: 三關各用「9 顆氣泡 + 2 顆拖曳 + 沾上 / 已鎖定 / 沾錯 / 踩拍 2、3 級同時 + 預告中 + 危險」截圖驗過: 色可辨、回饋找得到、血量環與拍子提示分得開。
- P13 事件排隊: 同一顆同時沾色又賦形時第二個光環晚 0.08 秒、起點大一圈; 內圈邊緣由內到外分帶: 危險紅光(174~211)→ 血量環(214~228)→ 拍子提示(234~266), 互不疊。
- P15 回饋強度和份量成正比: 每拍變化(本體內 2.5 像素邊 + 高光跳)< 出批(淡水紋)< 觸發(白細環 + 勾)< 踩拍第 1 級(1 圈共鳴輪廓 + 光暈)< 第 2 級(2 圈)< 第 3 級(3 圈、最內圈白、光最強)< 整串(實心閃光 + 20 根音浪條 + 外白環)。
- P17 進度圖形與數字分工: 血量沒有數字, 血量環畫總量(玩家要比的就是還剩多少); 壽命環無數字, 畫總剩餘比例; 歌曲進度只有圖形, 而且做成播放頭而不是填滿條, 不和血條同形。
- P18 重要資訊不只一瞬間: 回血 / 扣血除了動作處回饋, 血量環與血條上都留 0.6 秒亮段。
- P19 資訊貼著物件: 血量環貼在玩家視線所在的內圈外緣; 踩拍、沾上、已鎖定回饋長在那顆氣泡本身; 光門條件在亮邊上; 跳位預告畫在目標那一邊; 輪轉預告畫在地板間隙。依本輪縮邊界: 事件回饋不在物件旁另掛帶框標籤或級數記號。
- P21 示意圖選分岔例子: 說明第 1 頁碰到光門那一格指標仍按著(對照「要放手才算」); 第 2 頁左右只差擦過的是 A 還是 B, 右格的消失回饋畫在剛碰到 B 邊緣那一刻, B 留在旁邊看得到; 第 3 頁兩顆起點相同, 只差有沒有被按住。

## 5. 物件表

共同: 每個函式 `(ctx, state)`, 自己 save / restore。`level` 缺省 1。`t` 若無特別說明是「該演出開始後經過的秒數」, 時長見第 7 節 `Art.timing`; 超過時長就不要再呼叫。全部隨暫停凍結(暫停時不推進 t / phase / beatPhase / time / beat)。
