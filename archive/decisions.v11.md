# 定案結果

## 遊戲名(暫定)
捕泡手

## 一句話概念
中央圓形場地裡散布染色區, 不斷冒出透明氣泡; 場地周邊同一時間只亮一張捕捉網, 位置與條件都隨機, 收下一顆就換到別處換條件。玩家要在很短時間內一再判斷「這次要沾什麼、從哪裡擦、往哪個方向送」, 用滑鼠畫出又快又準的路線。

## 核心循環
看一眼現在亮的網在哪、要什麼條件 → 挑一顆氣泡 → 規劃一條「經過需要的染色區、再衝向那張網」的路線 → 放進去, 得分、回命, 網立刻換到另一個位置、另一個條件 → 下一次判斷的答案完全不同。生成越來越快、條件越來越複雜, 撐到命歸零為止。氣泡一批一批出現、每批排成一個陣型, 批與批之間有短暫空檔; 在下一批出現前把場上清空就是一次「清場」。想再玩一次的動力是「這次判斷更快、路線更俐落, 清場更多次、撐更久」。

v11(第 5 輪老闆回饋): 線性勻速生成沒有起伏; 改為「一批短時間湧出 → 空檔 → 下一批」的波次節奏, 每批排成形狀增加趣味, 趕在下一批前清空給玩家明確的成就點。

v9(第 4 輪老闆回饋): v8 的問題是「模式非常固定」: 網固定、條件固定, 玩家永遠重複同一條路線, 選哪張網都沒差, 很無聊; 電流急急棒被過度強調。v9 回到中央場地 + 周邊網的骨架, 讓「每一顆的答案都不一樣」, 要強化的是「很忙碌地在短時間內不斷快速判斷滑鼠要精準移到哪裡、走什麼軌跡」的刺激感。

## Demo 要驗證的問題
「同時只亮一張網、位置與條件隨機換」之後, 玩家能不能在一局裡持續感受到「短時間內快速判斷落點與路線」的忙碌刺激感, 而不是在重複同一個動作? 波次生成能不能讓玩家在「湧出 → 清空」之間感受到明確的成就點(清場), 同時不產生等待空檔?

## 確定要有的
- 操作: 只用滑鼠(守則 R1)。暫停、重開、放棄、說明翻頁一律用畫面按鈕
- 場地: 畫面中央一個圓形場地(內圈), 周邊一圈固定的網槽位(數量由規格定, 方向 6~8 個)。同一時間只有一張網亮著(啟用), 其餘槽位不收
- 網: 亮著的那張有一組條件(初期只有顏色, 後期疊形狀); 成功收下一顆後, 立刻在「另一個」隨機槽位亮起下一張, 條件也重新隨機。新網的位置與條件出現的那一刻玩家就要重新判斷
- 染色區(與後期的賦形區)全部在內圈裡面, 氣泡拖曳擦過才生效(閒置在上面不算); 抓起時已相交不算擦過
- 每種屬性只沾一次(v10 改, 取代「最後擦過覆蓋」): 只有透明的氣泡會被染色, 只有圓形的氣泡會被賦形; 已沾上的再擦到別塊不變。理由: 區域在內圈、網在外圈, 覆蓋規則下約七成出圈方向會半路擦到別塊把顏色蓋掉, 又變回「要避開」; 只沾一次讓半路擦到無害, 沾錯的氣泡成為之後別張網的存貨, 「挑哪顆送」偶爾成為真判斷
- 氣泡: 生成透明圓; 壽命 12 秒, 以環顯示, 歸零消失扣 1 命; 按住或拖曳中壽命凍結; 彼此碰撞不重疊; 只在內圈生成; 生成不擋、強制放置
- 波次生成(v11, 取代勻速生成率 + 最大間隔 5 秒 + 開局預放 2 顆): 氣泡以「批」出現。一批 N 顆在短時間內(約 1 秒內)依序冒出, 排成一個陣型(例: 一直線、弧、三角、圓環、十字等, 種類與座標由企劃定, 陣型點位要避開區域塊, 免得「抓起時已相交不算擦過」一抓就廢); 一批出完後是空檔, 空檔結束出下一批。開局第一批立即出現
  - 清場: 場上氣泡全部離場(捕捉或過期)時下一批還沒出現 → 算一次清場, 給清場獎勵(加分 + 明顯的成就回饋), 並把剩餘空檔縮短到很短(約 1 秒, 數值定)立刻出下一批。理由: 清場後再乾等幾秒就是「沒事做」, 違背驗證問題; 縮短空檔讓手快的人自然被加速, 是獎勵也是難度自適應
  - 沒清場: 空檔照常結束就出下一批, 上一批殘留的氣泡繼續留在場上(壽命照走), 疊加壓力
  - 難度: 隨階段每批顆數 N 增加(開局約 4 顆, 老闆原話)、空檔縮短; 波次參數與階段表連動, 由數值定。陣型種類可隨階段增加
- 清場要算「過期」嗎: 算。過期離場也是離場(已扣命), 清場只看場上是否空了; 數值若算出「放著過期換清場」划算, 改為過期的那批不給清場獎勵
- 已沾色的氣泡可以放回內圈留著, 等之後條件對上的網再送(數值: 刻意備料仍虧, 存貨主要來自沾錯與送錯彈回, 占捕捉 3~8%)
- 捕捉判定: 放開在亮著的網上, 氣泡屬性符合全部條件 → 捕捉(得分、連續 +1、回 1 命、網換位換條件); 不符 → 彈回內圈、不扣命、屬性保留; 放開在沒亮的槽位或其他地方 → 彈回或留在內圈
- 難度: 階段制, 每階段 40 秒加一種要素, 生成率在階段內緩升、階段間連續。v10 階段表: 1 開局就 3 色(A、B、C; 數值: 2 色時下一張 2/3 是換另一色, 近乎二選一)→ 2 加 D → 3 加方(疊形狀 25%)→ 4 加三角(40%)→ 5 區域縮小, 到局末
- 網輪替: 新網亮在原位與左右相鄰以外的槽位; 同一條件最多連 2 張; 拿掉「隔 2 格時條件必換」; 階段生效後第一張保底用新要素, 兩次切換之間都沒捕捉時保最新階段
- HP 上限 4, 捕捉回 1, 歸零結束; 結束畫面顯示存活時間與分數
- 計分: 抓對得分, 連續抓對加成; 送錯網彈回與過期歸零連續; 清場另加分。結束畫面多顯示清場次數
- 遊戲內玩家說明畫面(守則 R2), 首次進站自動開一次
- 試玩行為紀錄與每局自動下載 JSON(守則 R3)
- 邊界情況沿用 v8(失焦、視窗外放開、按鈕上放開、局結束中止拖曳、同幀命變化、HUD 稱命、按住未拖、彈回中不可按、拖曳限畫面內、快速拖曳不漏判)

## 明確不做的
- 鍵盤操作(守則 R1)
- 音樂與音效(等玩法定案後依守則 R5 再議)
- 局外成長、解鎖、商店、排行榜
- 洗除區與任何「要避開的區域」(v9 移除: 老闆要弱化急急棒)
- 管道、牆、窄縫版位(v9 移除)
- 多張網同時亮著
- 網上的數字、雙擊續命、網冷卻
- 勻速 / 線性增長的連續生成(v11 改波次)
- 區域放在內圈外
- 條件不符扣命(只彈回)

## 數值方向
- 目標單局時長: 首局新手約 2.7 分鐘, 熟手約 4 分鐘
- 手速基準用實測: 第 3 輪(v6)與第 4 輪(v8)的紀錄都交數值; 老闆落在模型的新手值(決策慢、手快)
- 同時只亮一張網時, 處理量上限是「一顆一顆排隊送」, 生成率不能超過單顆處理能力太多; 數值要重建: 每顆處理時間 = 看網 + 挑氣泡 + 路線(內圈內擦區 + 衝出內圈到網)+ 回程
- 「忙碌刺激」的來源是判斷頻率, 不是路線難度: 每顆的答案要不一樣(網位置與條件的隨機要避免連續兩次相同或太相近)
- 數值要回答: (1) 每顆處理時間與各階段生成率上限 (2) 「備料」策略(先把氣泡沾好色留著)的收益會不會大到讓玩家不用判斷 (3) 網位置與條件隨機的規則(排除上一張的位置 / 條件等)對判斷頻率的影響 (4) 什麼時候場上會空(沒事做), 怎麼避免 (5) 熟手 / 新手差距
- 關鍵參數(數值 v9 r1、r2): 內圈 (640,360) 半徑 210; 8 槽位距圓心 300; 區域環半徑 140、區域半徑 24(階段 5 起 20), 通道 52 像素(第 4 輪實測老闆過 40 像素就放慢); 網判定 60(實測放網最遠 56.7, 不可縮); 壽命 12 秒; 開局生成率 0.50、斜率 0.0042、最大間隔 5 秒; 開局預放 2 顆; HP 4 每次捕捉回 1。預測新手約 155~170 秒、熟手約 225~240 秒; 最敏感是決策時間(每顆 +0.1 秒死亡提早 13 秒)
- 第 4 輪實測校正: 按下到判成拖曳 0.08 秒; 抓起到擦區 0.22 秒; 移動 0.15 + 距離 ÷ 1100 像素/秒; 過 40 像素縫放慢(每縫 +0.47 秒); 放下到下次按下中位 0.59 秒; 處理時間逐段相加成立; 命只在生成率 > 2 × 處理率時淨減, v8 死在處理率崩盤

## 埋點
v11 新增(波次): 波次事件(批序號、陣型、顆數、出完時刻、空檔長度、是否清場、清場時刻與縮短後的空檔、清場時這批有幾顆是過期離場)、每顆氣泡所屬批序號、下一批出現時上一批殘留顆數、每秒取樣加「場上屬於幾批」; 波次參數的假設由數值在 spec-review 重列。原「開局預放 2 顆」「最大間隔」相關欄位刪除。

每局結束自動下載 JSON, 檔名照守則 R3。沿用 v8 的事件結構(生成、按下、按住未拖、抓取、擦過、放下、捕捉、消失、階段切換、命變化、暫停、每秒取樣、局結束殘留), 刪掉洗除 / 窄縫 / 牆相關欄位, 新增: 網出現事件(槽位、條件、與上一張的位置差與條件差)、每次抓取時「當下亮著的網的槽位與條件」「這顆氣泡當下屬性是否已符合」、網出現到被捕捉的時間(判斷 + 執行時間)、備料行為(沾色後放回內圈的次數、之後被哪張網收)。假設清單由數值在 spec-review 重列。

假設 E1~E17 與新增欄位見 discussions/spec-review-v9-r1-balance.md; v10 補: 擦過分類加「已鎖定、屬性沒變」、首次沾色是否為當下網要的、沾錯泡去向(捕捉 / 過期 / 殘留); 拖曳時長一律從按下起算; 「放下到下一次按下」全記(v8 漏記)。

### 回答驗證問題用
主要指標(以命歸零結束、第 2 局以後; 首局另看):

| 指標 | 門檻 |
|---|---|
| 1 網在場時間(網出現時可處理 ≥ 1) | 一項條件中位 1.3~2.2 秒; 兩項 ≤ 3.0; P90 ÷ 中位 ≤ 2.0; 階段 1→4 中位升幅 ≤ 35%; 槽位差 4 格與 2 格中位差 ≤ 0.4 秒(超過是換位提示不足 / 在找網) |
| 2 場上沒事做占比 | 0~60 秒 ≤ 10%; 之後 ≤ 3% |
| 3 最長無捕捉間隔(死前 30 秒以外) | ≤ 6 秒; 階段 2 起每分鐘捕捉 ≥ 28 |
| 4 送錯彈回率 | 階段 1~2 ≤ 8%, 3 起 ≤ 15%; 放不亮槽位 ≤ 3% |
| 5 命 ≤ 2 | 占比 5~20%; 首次出現 ≥ 單局 55%; 最後滿命到死 ≥ 20 秒(否則死得太突然, 再議回血頻率) |
| 6 清場(v11) | 門檻由數值在 spec-review 依波次參數定; 方向: 前段多數批能清場、後段清場變難但不歸零; 清場後到下一批出現的空檔不算「沒事做」也要看占比 |
| 輔助 | 單局時長新手 145~180、熟手 215~260; 存貨完成占比 ≤ 20%; 強制放置 ≤ 5 次 / 局; 沾錯率 |
- 老闆的三題: 玩法還在大動, 老闆表示現在回答沒有意義; 暫停, 玩法穩定後再恢復

## 留給規格階段決定的
- 內圈大小、網槽位數與位置、染色區數量位置大小(都在內圈裡)
- 網的下一張位置與條件的隨機規則(至少排除原位)
- 階段表: 各階段加哪種要素
- 賦形區是否保留(方向: 後期階段在內圈裡出現, 網條件疊形狀)
- 說明頁內容
