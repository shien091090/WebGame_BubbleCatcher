# 捕泡手 美術規格(style.md)

RD 只需讀本檔。`art.js` 掛在 `window.Art`, 非 ES module。art.js 內含中文字串, `index.html` 必須有 `<meta charset="utf-8">`, 否則 file:// 下所有文字變亂碼。

本版(v8 規格, 管道版位)相對 game-v6 的變動:
- 版面整個換成管道版位: 內圈移到左側 (330,360) 半徑 160; 網 8 張改 4 張; 新增 25 塊區域(染色 4、賦形 2、洗除 19)。所有座標、半徑、窄縫都在 `Art.layout`, 直接讀
- **新增 `drawPaintZone`、`drawShapeZone`、`drawWashZone`、`drawStageNotice`, 需要 RD 接**
- `drawNet` 改寫: 刪除 `target`、`next`、`targetFx`(網上數字全部刪除); 新增 `status`、`shape`、`nextShape`、`previewT`、`introT`; `flash` 刪除 `'wrong'`(條件不符一律 `'bounce'`, 傳 `'wrong'` 也照 bounce 畫)
- `drawBubble` 改寫: `color` 可為 `null`(透明); 新增 `shape`、`life`、`lifeMax`、`swipeFx`、`swipeKind`; 刪除 `timer`(改名 `life`)與 `renewFx`; 氣泡上不再有數字, 壽命環改畫 12 秒總剩餘比例(v6 的「一圈 = 這一秒」隨數字一起刪除)
- `drawHud`、`drawPauseButton`、`drawPauseMenu`、`drawInputSelect`、`drawEndScreen`、`drawBackground`、`drawInnerRing` 函式名與 state 不變(內圈只改位置與半徑)
- `drawTitleScreen` state 不變, 裝飾氣泡改成透明 / 圓 / 方 / 三角
- `drawGuidePage` state 不變, 6 頁內容依 v8 guide.md 全部重畫

## 邏輯畫布尺寸

1280 × 720(`Art.canvas.width / height`)。所有座標皆為此邏輯解析度。

## 形狀語言

圓形為主、圓角面板、扁平填色; 有色 = 實心, 無色 = 空心灰白框; 地塊是平的(無高光), 中央放一個說明效果的符號(水滴 = 染色、空心形狀 = 賦形、紅斜紋 = 洗除); 預告中 = 虛線框 + 由中心長大的填色; 新出場 = 四個白色角框。

## 理念落實

- P0 辨識度先於好看: 氣泡(有高光 + 壽命環、半徑 20)、染色區(平的色池 + 水滴、半徑 30)、賦形區(灰藍地面 + 空心形狀)、洗除區(紅斜紋警示帶、半徑 40)、網(網格 + 5px 色框、半徑 60)五種物件大小與紋理各不同, 靜止截圖就分得出; 每種物件的每個狀態(未出場 / 預告中 / 出場提示中 / 生效中; 閒置 / 按住 / 拖曳 / 彈回)各有獨立外觀
- P1 視覺權重跟著決策迫切度: 最亮的是氣泡與網(玩家此刻要動、要送的東西); 洗除區共 19 塊, 框與斜紋都降到半透明, 讀得出「危險」但不壓過網與氣泡; 快過期用全場唯一的紅色壽命環; 勾貼在網的右上緣, 不蓋住網中央的形狀條件
- P2 規則上存在的東西畫面上就存在: 未啟用的網畫成灰色虛線空槽(規則上不收); 預告中的區域 / 網 / 條件都畫出來但長相不同(不生效); 凍結(冰藍環)、彈回中不可按(半透明)、回命(那一格放大 + 白環)都有外觀
- P3 一個意義一種長相: 半透明只給「彈回中」, 所以預告不用半透明, 改用虛線框 + 長大中的填色; 灰白 clear 只代表「無色」(透明氣泡、賦形區); 紅只代表危險 / 損失(洗除區屬此類); 白角框只代表「剛出現 / 剛改變」; 網條件的形狀符號與氣泡、賦形區共用同一套形狀路徑; 說明頁的網、氣泡、區域、命、結束畫面直接呼叫遊戲內畫法
- P4 關鍵區分至少兩條通道: 老闆已明言 prototype 不考慮色弱, 四色只靠色相 + 明度; 語意不同的狀態走兩條通道: 透明 vs 有色(空心 / 實心 + 色相)、預告 vs 生效(虛線 / 實線 + 填色是否填滿)、凍結 vs 走動(環色 + 放大 / 影子)、捕捉(白 + 勾)vs 條件不符彈回(白虛線環、無符號)、回命(白環 + 放大)vs 扣命(紅框 + 空心)、擦過染色(新色實線環)vs 擦到洗除(紅虛線環)
- P7 每個元素要掙得版面: 網只要顏色時中央不放任何符號(網本身的顏色就是條件); 氣泡上不放數字; 網與區域上不寫名稱字樣; 暫停按鈕的「暫停」字樣是規格明文要求。階段切換預告條有一行「場地即將改變」, 與物件本身的預告部分重述, 見文末「與理念的張力」
- P13 事件要排隊: 場上只有一條文字(預告條), 且只在預告 2 秒內出現; 出場提示不用文字橫幅, 角框貼在各物件上, 2 秒內自己淡掉
- P17 進度類資訊, 圖形與數字分工: 氣泡上沒有數字, 依本條邊界「沒有數字、只有圖形時, 圖形照舊畫總進度」, 壽命環畫 12 秒總剩餘比例; 預告的填色與預告條都畫「離生效還多久」
- P18 重要資訊不能只存在一瞬間: 出場提示消失後, 新區域、新網、升級後的形狀條件本身常駐在場上; 扣命 / 回命閃光之後, 愛心實心與空心常駐; 分數與存活時間常駐 HUD, 結束畫面再列一次
- P19 資訊貼著物件: 條件畫在網上; 壽命畫在氣泡上; 預告與出場提示畫在那塊區域、那張網上; 勾畫在那張網上
- P21 示意圖選分岔例子: 第 1 頁同一顆氣泡擦過前是空心透明、擦過後是實心色 A, 分開「本來就有色」與「擦了才有」; 第 2 頁同一張色 A 網, 色 A 收下打勾 vs 透明放上去回到內圈且命前後同為 3 格, 分開「放錯會扣命」的誤解; 第 3 頁兩顆環同起點, 只有按住的那顆不走; 第 4 頁牆畫出空隙但箭頭刻意擦過牆塊本身, 分開「牆擋路」與「牆洗色」

## 物件表

所有函式簽章固定 `(ctx, state)`, 每個函式內部自行 save / restore。state 內沒寫預設值的欄位為必填。「未出場」的區域不呼叫; 未啟用的網照樣呼叫(畫空槽)。

| 物件 | 函式 | state 欄位 | 各狀態視覺差異 |
|---|---|---|---|
| 內圈外區域 | `drawBackground(ctx)` | 無 | 整面 bg 深色, 與內圈的亮一階地面對比; 中庭、牆後空地都是它, 不另畫 |
| 內圈 | `drawInnerRing(ctx, state)` | 無(state 可省略) | 固定: 圓心 (330,360) 半徑 160 的亮一階圓 + 3px 邊線 |
| 染色區(染 A~D) | `drawPaintZone(ctx, state)` | `x, y`: 中心(用 `Art.layout.zones` 裡該塊); `color`: 0~3; `status`: `'preview'`/`'on'`(預設 on); `previewT`: 預告進度 0→1(預告 2 秒, 1 = 生效那一刻); `introT`: 出場提示進度 0→1(生效後 2 秒; 0、≥ 1 或不傳 = 不畫) | 生效中: 半徑 30 的平色池(該色 50% 填色 + 3px 實線色框)+ 中央白框水滴; 沒有高光與壽命環, 跟同色氣泡分得開。預告中: 色虛線框 + 由中心長大的淡色填色(previewT = 1 時剛好填滿)+ 虛線水滴。出場提示中: 生效外觀 + 四個白角框(先縮進再輕脈動, 最後 0.4 秒淡出) |
| 賦形區(方、三角) | `drawShapeZone(ctx, state)` | `x, y`; `shape`: `'square'`/`'triangle'`; `status`、`previewT`、`introT` 同染色區 | 生效中: 半徑 30 的灰藍地面 + 3px 灰白框 + 中央空心形狀(灰白 3px); 不帶任何顏色。預告中: 灰白虛線框 + 長大中的地面 + 虛線形狀。出場提示中: 加白角框 |
| 洗除區(洗 1~19) | `drawWashZone(ctx, state)` | `x, y`; `status`、`previewT`、`introT` 同染色區 | 生效中: 半徑 40 的深酒紅地面 + 同方向紅斜紋(警示帶)+ 2.5px 半透明紅框; 全部斜紋同方向, 一排排起來連成一道牆。預告中: 紅虛線框 + 長大中的斜紋地面。出場提示中: 加白角框(階段 2 一次 10 塊同時出, 屬正常) |
| 網(網 1~4)/ 網條件 | `drawNet(ctx, state)` | `x, y`: 中心(用 `Art.layout.nets[i]`); `color`: 0~3(用 `nets[i].color`); `status`: `'off'`(未啟用)/`'preview'`(預告啟用, 仍不收)/`'on'`(啟用中)(預設 on); `shape`: 目前生效的形狀條件 `null`/`'square'`/`'triangle'`(預設 null = 只要顏色); `nextShape`: 預告中的新形狀條件(預設 null = 沒有升級預告; 升級期間 `shape` 仍傳舊條件); `previewT`: 預告進度 0→1(啟用預告與升級預告共用); `introT`: 出場提示 0→1(剛啟用或條件剛升級, 2 秒); `hot`: 拖曳中且指標在這張啟用中網的判定半徑內(預設 false; off / preview 時不畫); `flash`: `'catch'`/`'bounce'`/null; `flashT`: 0→1 演出進度, 建議 0.5 秒 | off: 灰色虛線圈、無網格、無顏色 = 空槽, 不收氣泡。preview: 灰底 + 該色虛線框 + 由中心長大的淡色填色(不畫網格, 仍看得出還不是網)。on: 淡色底 + 網格 + 5px 色框; 網的顏色就是顏色條件, 只要顏色時中央不放符號(不畫圓, 避免讀成「要圓形」)。形狀條件: 網中央深色圓盤 + 網色實心形狀 + 白框。升級預告: `shape` 為 null 時中央畫虛線形狀 + 長大中的填色; `shape` 有值(方 → 三角)時舊條件縮到左側、右箭頭、新條件虛線在右側。出場提示: 白角框。hot: 外圈 3px 白環。catch: 白環外擴 + 網右上緣白勾。bounce(條件不符): 白色虛線環, 無符號 = 沒扣命 |
| 氣泡 / 氣泡壽命環 | `drawBubble(ctx, state)` | `x, y`: 中心; `color`: `null`(透明)/0~3; `shape`: `'circle'`/`'square'`/`'triangle'`(預設 circle); `life`: 剩餘壽命秒(浮點, 按住 / 拖曳中由 RD 停住); `lifeMax`: 預設 12; `mode`: `'idle'`/`'hold'`/`'drag'`/`'return'`(預設 idle); `swipeFx`: 擦過回饋 1→0, 建議 0.35 秒, 屬性真的改變時觸發(預設 0); `swipeKind`: `'paint'`/`'shape'`/`'wash'` | 本體: 有色 = 該色實心 + 左上高光; 透明 = 空心玻璃(淡填 + 2.5px 灰白框 + 高光), 一眼看出還沒沾色。形狀: 圓 / 圓角方 / 圓角三角, 都在半徑 20 內畫得下(判定一律半徑 20 的圓, 不隨形狀變)。壽命環: 半徑 26, 從 12 點鐘順時針畫剩餘比例 life / lifeMax; idle 白色, 剩 3 秒內紅色加粗; hold: 放大 1.06、環變冰藍加粗(凍結), 無影子; drag: 放大 1.15 + 地面影子、環冰藍; return: 整顆 45% 透明(不可按), 環照走。swipeFx: paint = 新色環外擴; shape = 灰白環外擴; wash = 紅虛線環外擴。壽命歸零那幀請直接移除, 不另畫消失(說明頁有示意)。重疊不另畫, 照畫即可 |

### 判定幾何(`Art.layout`)

點擊與區域判定請直接讀 `Art.layout`, 與畫面保證一致(矩形皆為 `{x, y, w, h}`, x/y 為左上角; 圓為 `{x, y, r}`):

- `layout.canvas` {0,0,1280,720}; `layout.dragBounds` {20,20,1240,680} = 拖曳中氣泡中心的限制範圍(x 20~1260、y 20~700)

- `layout.nets[0..3]` = {id, x, y, color, stage}: 網 1 (900,190) 色 0 階段 1、網 2 (900,530) 色 1 階段 1、網 3 (1180,300) 色 2 階段 3、網 4 (1195,650) 色 3 階段 4

### 繪製層級(由下而上)

1. `drawBackground`
2. `drawInnerRing`
3. `drawWashZone`、`drawPaintZone`、`drawShapeZone`(已出場或預告中的區域; 區域彼此不重疊, 順序不拘)
4. `drawNet` × 4(含未啟用)
5. 閒置、被按住與彈回中的 `drawBubble`
6. 拖曳中的 `drawBubble`(永遠最上層的遊戲物件; 拖過區域或網時蓋住它們, 屬正常)

### 與理念的張力(交製作人決定)

- 階段切換預告條(`drawStageNotice`)的「場地即將改變」與各物件自己的預告外觀部分重述(P7)。保留理由: 玩家拖曳時視線在氣泡上, 場上其他地方冒出虛線框不一定看得到; 規格待定第 1 條擔心階段 2 一次出 10 塊洗除區看不懂。若試玩覺得多餘, 不呼叫即可, 其他畫面不受影響
- 牆的封死縫(兩塊洗除區邊緣間隔約 25 像素 < 氣泡直徑 40)只靠間距本身表達, 沒另畫連接帶。若試玩出現「以為縫過得去、硬擠被洗掉」(階段 2 錯擦暴增), 下一版可在封死的相鄰兩塊之間加一條暗紅連接帶
