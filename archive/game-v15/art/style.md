# 捕泡手 美術規格(對應 spec v15)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文字串在 file:// 下會變亂碼。
> art.js 以一般 `<script>` 載入, 產生全域 `window.Art`。全部 Canvas 2D 幾何, 無外部資源。

## 1. 邏輯畫布尺寸

1280 × 720(`Art.canvas`)。內圈圓心 (640,360) 半徑 210; 網牆正八邊形每邊中點距圓心 300、頂點約 324.7(頂點在 22.5° + 45° 倍數); 地板環半徑 140。

**一組函式畫三套**: 幾乎每個 draw 函式的 state 都有 `level`(1 / 2 / 3, 缺省 1), 換關時 RD 只要把 `level` 換成新關即可整套換風格。

### v15 與上一版(v14)的差異, RD 要接的

| 類別 | 項目 |
|---|---|
| 新增函式 | `drawRotateCue`(第 2 關輪轉預告)、`drawBatchCue`(出批提示)、`drawMissFx`(沾錯消失回饋) |
| 刪除函式 | `drawClearFx`(清場回饋與「清空」字樣), 匯出表已一起刪, 請移除呼叫 |
| 改 state | `drawBackground` 多收可省略的 `time`、`beat`(背景動態); `drawNetWall` 的 `lit` 多 `jump`(第 3 關跳位預告), `catchFx` 多 `x`、`y`(碰網點); `drawHud` 的 `hpFx.kind` 多 `'miss'`; `drawGuidePage` 的 `page` 為 1~8 |
| 時長表 | `Art.timing` 新增 `batchCue`、`missFx`, 刪除 `clearFx` |
| 其他匯出 | `Art.guidePages` = 8 |

**4 色的辨識規則(三關都一樣, node 驗算過)**:
- 色相: 同一關 4 色兩兩至少差 66°(第 1 / 2 / 3 首最小差 75° / 66° / 77°), 沒有任何一對落在相鄰色相(紅 & 橘、橘 & 黃這類)。上一版最小只差 27°(第 3 首琥珀 41° vs 黃綠 68°)、46°(第 1 首珊瑚紅 7° vs 檸檬黃 53°; 第 2 首橘 31° vs 桃紅 327°)。
- 第二通道 = 明度: 每關 4 色排成 4 個灰階階(暗 / 中暗 / 中亮 / 亮), 相鄰兩階至少差 35(第 1 首 81 / 128 / 170 / 214; 第 2 首 89 / 125 / 161 / 198; 第 3 首 68 / 114 / 151 / 225)。氣泡、網條件、地板、沾上標籤用同一個色碼, 明度階跟著色走, 所以三處一眼對得上。
- 主題色溫不由屬性色承擔: 暖 / 冷 / 無彩由背景、地面、網牆、HUD 表現; 屬性色只服從上面兩條。
- 拍子色每關都離 4 色色相至少 34°, 而且只用在線、弧、點(不用在實心圓面上), 不會被讀成第五色。
- 第 3 首背景與網牆全無彩, 全畫面的紅只留給 danger。

## 3. 形狀語言

可拿起的(氣泡)= 立體(放射漸層 + 高光 + 反光弧 + 常駐落影 + 深色外描 + 壽命環); 場景的(地板、內圈)= 平塗、無影、無高光; 每關只換「皮」(色溫、質感、背景動態、網牆造型、色組、拍子提示造型), 不換「骨」(上面這套分類手法)。第 1 首柔圓暖光(珠串網牆), 第 2 首冷霓虹發光管(雙管網牆、舞池格線), 第 3 首無彩硬角分節(鋼塊網牆、雷達掃描)。

## 4. 理念落實

- P0 辨識度先於好看: 主題色溫讓給背景與網牆, 屬性 4 色只服從「色相不相鄰 + 明度分階」; 三套風格只換皮, 「氣泡立體 vs 地板平塗」「透明空心 vs 有色實心」「亮邊粗線 + 白芯 + 黑襯底 vs 不亮細暗」三條分類線三關都不變。
- P1 視覺權重跟著決策迫切度: 亮著的網(粗 + 條件色 + 白芯 + 外光 + 內側柔光)與操作中的氣泡是全場最亮; 背景動態一律低不透明度、只在內圈與網牆之外; 出批提示只是地面兩道淡水紋。
- P2 規則上存在的東西畫面上就存在: 第 2 關輪轉、第 3 關跳位這兩個「沒捕捉也會發生」的變化都有預告; 沾錯消失有獨立回饋, 不讓氣泡無聲消失; 預備拍中不生效的新關地板用「虛線 + 未填滿」畫出來。
- P3 一本字典: 形狀路徑(圓 / 方 / 三角)氣泡、網條件、賦形地板、沾上標籤共用; 白 = 捕捉 / 凍結; 灰 = 已鎖定; 角框 = 剛出現; 虛線 + 由中心長大 = 還沒生效(地板預告、跳位「即將亮起」、輪轉預告的虛線軌都是它); 地面扁橢圓水紋 = 從地面冒出(單顆冒出、出批提示); danger 紅 = 扣命(過期、沾錯、危險); 拍子色只代表拍子。換關帶過的那一顆與舊亮網一起用舊關色組(`paletteLevel`)。
- P4 關鍵區分兩條通道: 4 色 = 色相(兩兩 ≥ 66°)+ 明度(4 階); 沾上 vs 已鎖定 = 顏色(有色 / 灰)+ 圖樣(色塊 / 鎖頭)+ 環的方向(外擴實線 / 內收虛線); 沾錯 vs 捕捉 = 顏色(紅 / 白)+ 形(叉 + 碎片 / 勾 + 環); 氣泡 vs 地板 = 立體有影 vs 平塗無影。
- P7 每個元素掙得版面: 清場回饋與「清空」字樣刪除; 網條件只畫有列的項目; 出批提示無字無星芒; 歌曲進度不寫數字; 拍子提示沒有字。
- P9 以最混亂那刻驗收: 第 1~3 首各用「7 顆閒置 + 2 顆拖曳 + 沾上 / 已鎖定 / 沾錯 / 踩拍同時出現 + 預告中」的截圖驗過色可辨、回饋找得到; 第 1 首背景改亮後, 亮邊加黑襯底、氣泡加深色外描, 拖到背景上照樣讀得到。
- P13 事件排隊: 同一顆氣泡同時沾色又賦形時兩個標籤用 `stack` 往上疊; 換關提示與預備拍數字分上下兩處; 出批提示與冒出水紋同一個語彙, 不另開視線落點。
- P15 回饋強度和份量成正比: 出批(兩道淡水紋)< 捕捉(舊邊白閃 + 白細環 + 勾)< 踩拍第 1 級(兩側 1 組音波弧 + 1 個拍點)< 第 2 級 < 第 3 級(3 組 + 外環 + 白弧)< 整串(實心閃光 + 20 根音浪條 + 外白環)。沾錯(碎片 + 紅叉)與捕捉同級, 份量差靠顏色而不是大小。
- P17 進度圖形與數字分工: 壽命環無數字, 照規格畫總剩餘比例; 歌曲進度只有圖形; 輪轉預告的弧長滿 = 輪轉那一拍, 跳位預告的填色長滿 = 跳位那一拍(沒有數字, 圖形畫到事件那一刻為止)。
- P18 重要資訊不只一瞬間: 回命 / 扣命除了動作處回饋, 命條上也留 0.6 秒亮段(沾錯也有)。
- P19 資訊貼著物件: 沾上 / 已鎖定標籤、踩拍拍點貼在那顆氣泡上; 網條件在亮邊上; 輪轉預告直接畫在地板與地板之間; 跳位預告畫在目標那一邊上; 沾錯回饋畫在消失處。
- P21 示意圖選分岔例子: 說明第 1 頁三個時刻讓「擦過 B 會變 B」的誤解畫出不同結果; 第 2 頁第 1 格氣泡停在亮邊上、指標仍按著就打勾(對照「要放開才算」), 第 3 格碰到不亮的邊什麼都沒有(對照「碰到哪一邊都會彈回」); 第 3 頁左右只差擦過的是 A 還是 B。

## 5. 物件表

共同: 每個函式 `(ctx, state)`, 自己 save / restore。`level` 缺省 1。`t` 若無特別說明是「該演出開始後經過的秒數」, 時長見第 7 節 `Art.timing`; 超過時長就不要再呼叫。全部隨暫停凍結(暫停時不推進 t / phase / time / beat)。

### 說明頁內容(第 1 首風格)

1. 沾色: 內圈 + 染 A、染 B; 一顆氣泡三個時刻(透明 → 擦過 A 變 A → 擦過 B 仍是 A), 箭頭到擦過 B 為止, 指標按著最後那顆; 無網牆。
2. 碰到亮著的網: 三格網牆 + 內圈, 右邊亮、要色 A, 箭頭只畫碰到前最後一小段, 無命、無扇區。① 色 A 氣泡停在亮邊上(碰到)、指標仍按著, 旁邊打勾; ② 透明氣泡碰到同一邊(虛線圈 = 碰網點)→ 虛線彎箭頭回內圈, 內圈裡一顆透明氣泡; ③ 色 A 氣泡碰到左邊不亮的邊, 指標仍按著, 沒有勾也沒有叉。
3. 沾錯會消失: 左右兩格, 都是右邊亮色 A + 內圈裡染 A(上)、染 B(下), 左上命都沒滿。左: 透明氣泡 → 碰到 A 變色 A(沾上標籤), 命 52 無變化; 右: 透明氣泡 → 碰到 B 的那一刻碎掉(碎片 + 紅叉), 命 52 → 49 一小段紅色亮段。箭頭只畫氣泡到染色區那一小段。
4. 網會換地方: 左: 右邊亮色 A、色 A 氣泡正碰到那一邊。→ 右兩格「或」: 左下邊亮色 A / 上邊亮色 B, 原本那邊都熄滅且都不在隔壁。無路線。
5. 抓著時環不走: 三格時間序, 每格兩顆透明氣泡放大; 被按住那顆環一直滿(白), 另一顆 滿 → 少一段 → 再少一段。無命、無網、無區域、無標注。
6. 命的增減: 三格, 每格左上有命(都沒滿)。左: 同一條命前後兩刻, 後一刻較短; 中: 色 A 碰到亮著色 A 的網 + 勾, 命多一段白色亮段; 右: 環走完的氣泡 → 原位變空, 命少一段紅色亮段。
7. 對上拍子: 上下兩排, 每排左上有命、右側放大內圈右半(含遊戲內拍子提示)。上: 擦過染 A 沾上色 A、拍子提示在拍點上(邊線閃光)、氣泡兩側第 1 級音波弧、命多一段拍子色亮段; 下: 同樣沾上(標籤照樣出現), 拍子提示在兩拍之間, 沒有踩拍回饋, 命沒多。無失敗記號。
8. 結束: 左: 命 30 → 12 → 0(危險狀態)。→ 右: 結束卡片只有「結束」與存活時間。
