## (2) 規則矛盾或沒定義的情況
- 對話框出現時左鍵已按著(不是帶過那顆)沒定義, 可能在「知道了」上放開就關掉, 或第 1 關結尾連點誤關。修法(寫進「形狀說明 / 關閉」): 「『知道了』只接受對話框出現之後才開始的按下, 而且按下和放開都要在按鈕上。對話框出現前就按著的左鍵, 放開時不觸發任何東西。對話框出現後 0.6 秒內(初始值), 『知道了』不接受點擊, 畫面要看得出還不能按」。
- 對話框期間歌曲進度、拍子提示、關末幀超過關末的時間沒寫; 埋點把對話框算進換關預備拍期間, 口徑不一致。修法(加在「形狀說明 / 對話框開著時」): 「歌曲進度不顯示; 拍子提示停住、不隨拍變化; 關末那一幀超過關末的時間捨去。第 2 關預備拍在點『知道了』那一刻從第 −4 拍起算, 局時間從關末那一刻接著走」。
- 換關空白時長口徑會被對話框撐爆: telemetry 用詞「換關預備拍期間」後補「時長類讀數一律以局時間計, 不含形狀說明對話框開著的時間; 對話框時長只記在形狀說明事件」。
- 輸入裝置殘留: telemetry 數值假設對照「判定中心與寬度」列刪掉輸入裝置; spec 加「舊版存在本機的輸入裝置設定一律忽略」; telemetry 跨版本比對加「上一版選了非滑鼠裝置的局, 不進跨版本對照」。
- 其他交互對過, 沒有矛盾。
