## 第 1 點 定案在規格中的對應
v22 兩條、v20 四條、v18 各條、數值定案都有對應。缺的兩個小地方:
- v21「不做節拍變化開關輪流」沒寫進範圍邊界; telemetry 節點事件「節點當下該顆的節拍變化是否顯示中」暗示有時不顯示。修法: spec 不做清單加「氣泡隨拍變化的開關、分局輪流對照(隨拍變化一律常開)」; telemetry 那欄改「節點當下的拍相位」, 刪「是否顯示中」。
- telemetry 第三題「時間差集中」的「待數值重核(spec.md 待定 15)」引用過時, 刪掉括號或改指向待定 20。

## 第 2 點 規則矛盾與沒定義的情況
- 換位當下即判的後備觸發後, 漸強 / 整串 / 回饋沒定義。修法(參數表該列與待定 22): 「後備觸發後, 換位當下即判的送進網仍是計次節點、照常判踩拍。踩拍時: 不給踩拍回血 2、不給踩拍回饋; 漸強級數照常累計(這顆已消失, 等於沒有作用); 整串照判, 成立時整串回血 2 與整串回饋也不給。埋點照記『是否踩拍』, 另記『後備扣除』」。理由: 只拿掉回血、回饋照給, 是與待定 28 同一種誤讀。
- 捕捉時計次節點數不可能是 1(光門一定有顏色條件)。telemetry 總量核對加「捕捉時計次節點數 = 1 的次數(應為 0)」。
- 光門要的屬性與光門換條件: 規則一致, 不用改, 但加重第 28 條誤讀。
- 同一幀先染上、後換位會被事後改判(只發生在卡住換條件那一幀, 實測卡住 0 次)。待定 8 末尾加: 「已知代價: 卡住換條件那一幀, 拍點前的染上以新光門判, 可能把當下合法的染上判成染錯; 因卡住實測 0 次, 接受」。
- 待定 28 的感受風險建議在回饋上處理:
  - 風險比寫的大: 第 2 關前段 75% 光門不要形狀, 往染色區路上容易擦到形狀區, 每局都會出現(估 2~10 次); 漸強跟著被拉低; 「差一點占比」只算計次節點, 量不到這類感受, 與 v22 方向相衝。
  - 方案 A(建議, 不改規則): 沾地板回饋狀態改「無 / 沾上(光門要的) / 沾上(光門沒要) / 已鎖定擦過」; 加「沒要求的屬性染上時, 給『沾上(光門沒要)』回饋: 照樣顯示染上了什麼形狀, 但強度明顯低於光門要的那種, 且不得帶任何跟踩拍回饋相似的元素, 讓玩家一眼讀成『這下光門不在意』, 而不是『判定漏了』」。
  - 方案 B(改規則): 光門沒要形狀時擦過形狀區不變形, 比照已鎖定擦過; 推翻 v22「照常染上」, 多一條規則, 數值要重估。
  - 方案 C(觀察): 待定 28 補觸發條件「每關平均沒要求染上 ≥ 3 次, 且其中原始時間差落在窗內 ≥ 50%, 或老闆局後原話提到『對上卻沒反應』→ 下版改走 A; A 之後仍出現同樣原話 → 提 B」。
  - telemetry「差一點」列並列「沒要求染上且原始時間差落在窗內」÷(計次節點數 + 這類次數)。
  - 建議本版做 A, 配 C 的觸發條件。

## 第 3 點 操作
足夠, 只用滑鼠。沒問題。

## 第 4 點 驗證問題
- 第 1、2、4 題不受影響。
- 第 3 題: 「更累」可能沒有對照組(新窗下踩拍率約 90%, 不踩拍型局可能 0 局)。修法: 「任一組少於 2 局時, 改用局內對照: 逐局『依踩拍數分組的網在場時間』, 踩拍數 2~3 對 0~1 的中位多 > 15% 算更累」。「主動對拍」的「踩拍率隨局數上升」卡天花板, 改「踩拍率隨局數上升, 或送進網原始時間差環狀四分位距隨局數變窄, 擇一」。
- 第 28 條風險落在第 3 題「更爽」上, 至少要並列補充讀數。
