# spec-review 第 15 版第 2 回合 回覆(數值)

## 1. A 案(換位那一刻已壓在新亮邊上 → 立即判碰網)

結論: 採 A 案, 數值上沒問題。踩拍回血照給(不另做配套), 只把這種送進網從第三題讀數排除, 另列觸發條件, 超過才改成不給踩拍回血。第 3 關不會因此明顯變簡單。

推算:
- 碰巧觸發: 網輪替保證新邊離舊邊至少 90°, 氣泡從衝出內圈到碰牆只走約 70 像素(約 0.07 秒)且在舊亮扇區內。每次跳位碰巧觸發 < 1%, 熟手第 3 關約 19 次跳位 → 每局 < 0.2 次。第 1、2 關自動換位沒有預告, 約 0。
- 學會之後: 預告 1 拍(0.46 秒)內手上剛好有一顆已備好、正要送網的氣泡, 每次跳位約 30%; 熟手每局約 6 次, 占第 3 關送進網約 18%、全局約 5%。刻意等不值得: 錯過預告要等下一次跳位, 平均約 1.85 秒, 損失約 9 血換約 1 血。
- 每次 A 案捕捉收支: 熟手約 +0.7 血、新手約 +1.4 血; 在邊外等拍平均約 0.23 秒 ≈ −1.2 血; 淨效果熟手約 −0.5、新手約 +0.2, 接近 0。
- 最壞情況: 每局 6 次 × 1.4 血 ÷ 69 秒 ≈ +0.12 血/秒, 熟手第 3 關存活 69.2 → 73.6 秒(+4.4), 實際接近 0, 約等於斜率 0.025 → 0.024。
- 不建議「換位當下碰網不給踩拍回血」: 是玩家看預告自己計畫的對拍, 拿掉牴觸「沒踩拍不罰」, 數值影響只有 0~4 秒。
- 真正的問題在讀數: 時間差固定 0 毫秒, 會灌高送進網踩拍率, 以 18% 占比估第 3 關虛增約 4 個百分點, 一定要排除。

| 參數 | 值 | 理由 |
|---|---|---|
| 換位當下碰網的踩拍回血 | 照給 | 有計畫的對拍; 淨收支約 0 |
| 第三題讀數 | 排除「換位當下碰網」的送進網節點, 另列一欄 | 第 3 關踩拍率約虛增 4 個百分點 |
| 觸發才改的條件 | 第 3 關「換位當下碰網」占送進網 > 25%, 或第 3 關存活中位比預測多 > 10 秒 → 改成不給踩拍回血 | 預估 18% / +0~4 秒 |
| 新埋點 | 碰網事件加「是否為換位當下碰網」與「換位前在新邊外側等了多久」 | 校正 30%、每局 6 次、等待 0.23 秒 |

## 2. 第四題: 扣除關卡特色成本

結論: 第 2 關每張網平均扣 0.06~0.11 秒(取 0.08), 第 3 關每張平均 0.08 秒; 換成「受影響的那張網」扣, 分別是 0.20 秒和 0.17 秒。等價的原始增幅門檻約 ≤ 20%。企劃寫的「跳位次數 × 0.08 秒」少算約 1.75 倍(0.08 秒本來就是平均到每一顆的值)。

推算:
- 第 2 關輪轉: 一顆氣泡碰到輪轉約 24%; 預告 2 拍後撞錯色新手約 15%、熟手約 7.5%; 撞錯成本約 1.9 秒, 沒撞錯也會停下來看約 0.15~0.2 秒。新手 0.11 秒/張、熟手 0.06 秒/張。網在場約 1.7 秒, 撞上輪轉的機率約 41%, 只扣受影響的網每張約 0.15~0.27, 取 0.20 秒。
- 第 3 關跳位: 每顆多 0.08 秒直接落在網在場時間; 一張網撞上跳位約 46% → 受影響的網每張約 0.17 秒。
- 百分比: 0.08 ÷ 1.70~1.75 ≈ 4.7%, 「扣除後 ≤ 15%」約等於「原始增幅 ≤ 20%」。
- 新地板擺位與新色組造成的變慢是第四題本來要量的, 不扣; BPM 改變的對拍等待量級小, 不扣。

| 參數 | 值 | 理由 |
|---|---|---|
| 第 2 關特色成本 | 窗口內撞上輪轉(網亮著期間發生輪轉)的網每張扣 0.20 秒, 其餘扣 0 | 平均 0.06~0.11 秒/張, 撞上機率 41% |
| 第 3 關特色成本 | 窗口內撞上跳位的網每張扣 0.17 秒, 其餘扣 0; 不用「跳位次數 × 0.08」 | 撞上機率 46% |
| 新鮮不變迷失: 增幅 | 逐張扣掉成本後取中位, 換關後對換關前增幅局間中位 ≤ 15%; 原始增幅 ≤ 20% 當對照一起報 | 平均成本約 4.7% |
| 換關後第 1~3 張 | 扣掉成本後每張多出 ≤ 0.45 秒(原始值另報) | 第一次輪轉 / 跳位在第 8 拍, 通常只碰到其中 1 張 |
| 新埋點 | 網出現事件加「在場期間經歷的輪轉 / 跳位次數」(回填) | 逐張判斷是否撞上 |

## 3. 第二題: 第二句判準

結論: 「批間等待中位 ≤ 1.5 拍」不能用。規則決定的期望值就是 1.5 拍, 老闆約 80% 的捕捉落在拍上, 分布集中在 1 拍和 2 拍兩端, 中位數會跳動, 約一半的局會無故不過。改看平均數和範圍; 「等待空檔」的感受改看 r1 的批間空白占比。

推算: 批間等待落在 1~2 拍之間; 最後一顆常在拍上清完, 拍後 30 毫秒清完約 1.94 拍、拍前 30 毫秒約 1.06 拍, 雙峰; 一局約 30 批中位可能落在 1.1~1.9 拍任何位置, 平均穩定約 1.5、標準差約 0.08 拍。每批 0 過期: 6 顆批首局新手約 88%、熟手約 98%; 4、5 顆批約 99.9%(出現過期幾乎一定是冷落某顆或卡住)。

| 參數 | 值 | 理由 |
|---|---|---|
| 批間等待範圍(實作驗收) | 每批都在大於 1 拍、不超過 2 拍之間; 超出即實作錯誤 | 規則保證 |
| 批間等待平均(取代中位) | 每局 1.35~1.65 拍; 換成秒第 1 關 ≤ 0.99、第 2 關 ≤ 0.86、第 3 關 ≤ 0.76 | 平均穩 |
| 批間空白占比 | (批間等待 + 首按延遲) ÷ 存活時間: 第 1 關 ≤ 20%、第 2 關起 ≤ 12% | 這才是「有沒有空檔」 |
| 每批 0 過期的批占比(警示) | 4、5 顆的段 < 95% 警示; 6 顆的段新手 < 80%、熟手 < 92% 警示 | 預估 99.9% / 88% / 98% |
| 讀法 | 4、5 顆的段觸發 → 看冒出到第一次按下與卡住段; 6 顆的段觸發 → 看每批約束實際餘裕, 必要時第 3 關改 5 顆 | 兩種成因不同 |

抓取順序和陣型出場順序的一致率: 沒有期望值, 只當描述, 不設門檻。
