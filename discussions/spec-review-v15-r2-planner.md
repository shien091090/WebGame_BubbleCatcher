## 追問 1: 碰網用 A 案還是 B 案

結論: 同意走 A 案, 但要改一處。換位那一刻, 手上那顆若已經壓在新亮邊上, 條件相符才收; 不相符就什麼都不發生, 不彈回、不歸零(A' 案)。

「等網」不是反對 A 的理由, 被三件事限住:
- 預告只有 1 拍, 130 BPM 下約 0.46 秒; 目標邊和原亮邊至少差 90°, 手上的氣泡要剛好在附近、已經對色才停得過去, 做不成固定打法。
- 預告期間原來那張網照常收, 直接送原網通常更快; 停在預告邊上等, 等於讓手閒最多 1 拍, 其他氣泡壽命照走。
- 白送收益有上限: 第 3 關約 3.7 秒跳一次, 每次最多多拿踩拍回血 2, 就算每次成功也只多約 +0.5 血/秒; 「在拍點落進網」本來就是節奏玩法想要的手感。

真正的體驗問題在條件不相符時: 照原 A 案會被當成「碰網不符」彈回、連續歸零, 玩家什麼都沒做就被罰(拖著別顆繞路剛好經過即將亮起的邊; 第 3 關卡住時跳位連條件一起換)。違反「沒做錯就不罰」, 所以不相符改成「沒反應, 離開再碰回才算」。

規格「碰網判定」加:
> - 亮網換位那一刻(第 1、2 關自動換位、第 3 關跳位; 捕捉輪替時不會有拖曳中的氣泡), 拖曳中的氣泡若已與新亮邊線段相交, 或中心已在新亮邊外側:
>   - 條件全部相符 → 該刻即判碰網捕捉(以下稱「換位當下即判」), 碰網時刻 = 換位那一刻; 送進網節點、踩拍、漸強、整串照常判, 回血照給
>   - 任一項不符 → 不判碰網: 不彈回、連續數不變、拖曳繼續; 要先離開(與亮邊線段不相交且中心不在亮邊外側)再碰回才判

telemetry 要補:
- 碰網事件「碰到的方式」加第三類「換位當下即判」
- 第 3 關跳位事件加「跳位那一刻是否有拖曳中氣泡已在新亮邊上(結果: 換位當下即判捕捉 / 不符未判)」
- 逐局「第 3 關跳位」加: 換位當下即判次數、占第 3 關捕捉數比例、占跳位次數比例; 不符未判次數
- 第三題判準「時間差集中」「在對拍」兩列補「換位當下即判的送進網節點不計入」
- 第四題「新鮮不變迷失」也排除這類捕捉

規格加待定 22:
> 22. 換位當下即判會不會變成「等網」: 待試玩。原因: 第 3 關跳位有 1 拍預告且落在拍點上, 停在預告邊上等亮起可穩拿送進網踩拍。初始門檻: 換位當下即判占第 3 關捕捉 > 15%, 或老闆提到「等網跳過來」→ 改為該節點不判踩拍(仍照常捕捉); 仍不夠再改「已在亮邊上一律要離開再碰回」。15% 為企劃初始值, 請數值核對

## 追問 2: 第四題「新鮮不變迷失」的寫法

telemetry「第四題判準」表「新鮮不變迷失」整列換成:

> | 新鮮不變迷失 | 窗口: 換關後 30 秒(從新關第 0 拍起; 進第 3 關取 29 秒)對比換關前同長度(到關末為止), 以存活時間計。只算一項條件、出現當下可滿足數 ≥ 1、以捕捉結束的網; 換位當下即判的捕捉不算。校正網在場時間 = 原始網在場時間 − 該網所在關的結構成本: 第 1 關 0; 第 2 關每張 c2(輪轉成本, 秒 / 張); 第 3 關每張 c3 + 該張在場期間只換位置的跳位次數 × j3(秒 / 次)。換關前、換關後窗口都照各自所在的關扣。校正增幅 = (換關後校正中位 − 換關前校正中位) ÷ 換關前校正中位; 第 n 張多出 = 換關後第 n 張(n = 1~3)校正值 − 換關前校正中位。c2、c3、j3 由數值給 | 校正增幅局間中位 ≤ 15%; 第 1~3 張每張校正後多出 ≤ 0.45 秒; 未校正的原始增幅與多出秒數另報, 描述用 |

配套: 逐局「build 版本與參數快照」末尾加「第四題結構成本(c2、c3、j3)」; 規格待定 17 之後加待定 23:
> 23. 第四題結構成本 c2、c3、j3: 待數值。原因: 第 2 關輪轉與第 3 關跳位本身就會拉長網在場時間, 不扣除會把「關卡特色的成本」誤讀成「換關後迷失」; 數值給初始預估, 試玩後用第 2、3 關關內中段(換關 30 秒以後)的實測回校

請數值確認: c2 先寫成每張平均扣固定值; 若有沒有碰到輪轉差很多, 改成「該張在場期間的輪轉次數 × r2」。
