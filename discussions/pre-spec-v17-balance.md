### 2. 新窗: 送進網 ±100 毫秒、補償 +20(各關相同, 用毫秒定)
±100 = ±1.47 個合併標準差, 理論命中 86%; 逐格重算第 1 關約 70 / 69 / 93%, 第 2、3 關約 85~92%; 全體 69.6% → 83%, 第 2、3 關 73.7% → 約 90%。不用拍比例定窗: 第 3 關四分位距(77~93 毫秒)沒比第 1 關窄。亂按基準送進網第 1 / 2 / 3 關 33.3% / 38.3% / 42.7%(128 BPM 計), 都 < 50%; 對拍玩家約 85~90%。「在對拍」標準化 0.32 不變, 換原始踩拍率 55% / 58% / 61%。
