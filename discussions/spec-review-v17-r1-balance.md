## 數值 spec-review 第 1 回合(v17 規格 / v22 定案)

結論: 規格和 telemetry 照抄 decisions v22 數值預算與第 3 關輪轉預告 3 拍, 逐條對過沒有抄錯或漏抄。要更新 4 處: telemetry「指標 5 預估」舊數字; 參數快照「第 9 輪分布套 +50 的基準踩拍率」過時; 第 1 關「第 15~23 秒起滿血」被第 10 輪推翻; 「差一點 < 5%」在現行判定窗下結構上達不到。玩法參數都不建議改。

### 一、推算過程

實測校正(A / B / C = 010720 / 081140 / 081730):
- 單局 149.7(死在第 2 關後段)/ 230.2 / 216.6 秒。
- 新分類(只看第 2、3 關送進網): A 局第 2 關掉拍(四分位距 274 毫秒 = 0.52 拍), 新窗估約 45%, 不踩拍型; B 局估第 2 關約 92%、第 3 關約 82%, 合計約 88%, 大部分型; C 局約 91% / 86%, 合計約 90%, 大部分型。樣本是 1 局不踩拍型 + 2 局大部分型, 半數型 0 局。
- 舊設定落在窗外 30.4%, 與 decisions 一致。
- 新推翻: 第 3 關血量下降集中在開頭, 不是線性。B 局第 3 關前段每秒淨血 −2.41、後段 −0.91; C 局 −2.28 / −1.36。前段 30 秒每秒觸發 0.33 次, 後段 0.42~0.43。線性模型積分總量對(時長仍準), 形狀錯, 影響指標 5。

(1) 單局時長: 熟手第 3 關每次觸發回血約 11.7, 每秒收入 4.33, 扣染錯 0.11、起點 5.2, 開頭淨血約 −0.98; 第 3 關存活 58.5 秒, 單局約 228 秒, 與規格 230(222~237)一致。熟手目標 240 差 −10(−4%); 首局或第 2 關掉拍 150~156 秒, 比 183 對照差 −27~−33, 低於輔助區間 165(待定 2 已寫)。

(2) 無解 / 無限延續: 不會無限延續(最晚單局約 339 秒); 不會提前無解(每批約束第 3 關 10.98 < 12, 要每顆 ≥ 2.50 秒才破, 實測 0 顆尾巴過期; 第 2 關卡住最多約 4.70 秒)。先碰到的是讀數門檻: 第 2 關批間空白實測 12.16% / 12.14% / 11.13%, 門檻 ≤ 12%, 結構值 10~12%。

(3) 難度斜率: 熟手每秒淨血第 1 關前段 +0.94 → 第 1 關後段到第 2 關後段約 0(滿血被溢出蓋住)→ 第 3 關前段約 −2.1 → 第 3 關後段約 −1.0~−1.4。不是斜率, 是「約 140 秒沒有壓力 + 進第 3 關的斷崖」。第 1 關實測第 19 / 37 / 31 秒起滿血, 新窗下估第 19~30 秒起, 無壓力約 56~67 秒(原寫 63~71)。

抄寫核對全部一致(判定窗與補償、亂按基準 200 ÷ 每拍毫秒、在對拍 54.7 / 58.0 / 61.0%、分類、預測、三條後備、敏感度、輪轉預告 3 拍無殘留、v22 埋點)。註記: 下限後備「約 +8 秒」與「±0.3 → ∓7」都對但不對稱(起點 −0.3 → +8.1, +0.3 → −6.8), 建議改寫「+0.3 → −7 秒、−0.3 → +8 秒」。
