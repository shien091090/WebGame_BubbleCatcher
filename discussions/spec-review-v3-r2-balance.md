# 第 2 回合: 追問回覆(沒有試玩紀錄, 仍是模型推算)

## Q1. 方案 B 加末命保護的時長與熟手 / 新手比

B 加末命保護: 新手約 170 秒、熟手約 209 秒, 比值 1.23, 達不到 1.4。**我修正第 1 回合的說法**: 降低斜率 k 只會拉大兩者的秒數差, 比值幾乎不動(k 從 0.004 降到 0.002, 比值都在 1.23~1.26)。原因是比值由「兩種手速各自在生成率多高時死」決定: 新手約 0.8 顆/秒、熟手約 0.93 顆/秒, 這個差和 k 無關。在只區分手速的模型裡, 1.4 要靠「判斷好的人撞窗錯過更少」才拉得出來, 而這正是 Demo 要驗證的問題, 不該用參數硬湊。k 越低前段越沒壓力, k 0.002 時第一次扣血約在 150 秒, 等於回到 v2 前段沒壓力的狀態, 所以建議 k 停在 0.003。

## Q2. 末命保護會不會被利用

故意「不續命讓網配合」行不通: 只有續命用完的氣泡才受保護, 要享受保護得先花兩次雙擊(約 0.8~1.0 秒手部時間), 換來的只是避開約 20% 的重抽錯失。平均每顆只省約 0.1 秒, 淨虧約 0.8 秒。場上同色有 2 顆以上末命氣泡、同時綁住網的機率約 5%, 綁住的後果是目標偏低(平均約降 0.5), 新氣泡要多等, 對玩家是變難不是撿便宜, 所以不用加限制。只埋警戒線: 觸發率超過 40%, 或平均目標低於 5.5, 就改成只保護「顯示倒數最低」的那顆; 用最低而不是最舊, 因為最低的最接近過期。

| 項目 | 量級 |
|---|---|
| 故意湊成末命的成本 | 兩次雙擊約 0.8~1.0 秒 |
| 故意湊成末命的收益 | 約 0.2 × 0.5 秒 ≈ 0.1 秒 |
| 重抽觸發保護的比例 | 前期約 10%、後期約 30% |
| 同色 2 顆以上末命同時綁網 | 約 5% 的重抽 |
| 平均目標的偏移 | 約 −0.5(6.5 → 6.0) |

## Q3. 捕捉循環 S 還要不要記, 撞窗損失係數 0.65 靠什麼校正

要記。S 決定手被一次捕捉占住多久, 而「開窗到抓取延遲 + 拖曳時長」少了「放下後回到下一顆」的回程時間。回程只取「放下那一刻, 下一顆要抓的已經開窗」的循環, 這樣不會混進等窗口的時間。0.65 的校正, 給 RD 的一句話: **每個窗口結束時記下原因(被抓取 / 倒數走過 / 網重抽換掉), 以及那 1 秒內玩家有多少時間在拖曳中; 「倒數走過」占所有窗口的比例就是實測撞窗損失, 除以用實測 S 與生成率套公式算出的值, 得到的就是新係數。**

| 要算的量 | 用哪些欄位 |
|---|---|
| S = 拖曳時長 + 回程 | 放下事件的拖曳時長, 加上「放下到下一次抓取」(只取放下時下一顆已經開窗的循環) |
| 實測撞窗損失 | 窗口結束原因為「倒數走過」的次數 ÷ 窗口總數 |
| 撞窗損失係數 | 實測撞窗損失 ÷ [ρ²/(1+ρ+ρ²)], ρ 用實測 S 與實際生成率算 |
