## Q1 末命保護改版後的「等不到」比例、時長、d=4 落空率

我修正第 1 回合的立場:原估的 5~8% 我重現不出來。我逐個 d 算過,保護救不回的重抽損失,新規則下約是沒保護時的 42%,舊規則約 54%,所以「等不到」占過期的比例新規則約 19~23%、舊規則約 23~28%,改版只少約 4 個百分點。新手 / 熟手時長只各多約 3 秒,所以維持 197 / 242 秒;原模型沒算「保護會救回剩 ≥ 4 的已錯過顆」(估 −21% 過期),也沒算保護沒救成的重抽(估 +24% 過期),兩項大致抵消,誤差約 ±5 秒。

| 項目 | 舊規則(≤ d,觸發 ≥ 3) | 新規則(≤ d−1,觸發 ≥ 4) |
|---|---|---|
| 保護救不回的比例(相對沒保護) | 54% | 42% |
| 「等不到」占過期,新手約第 120 秒 / 死亡前 | 28% / 23% | 23% / 19% |
| 新手 / 熟手時長 | 約 194 / 239 秒 | 約 197 / 242 秒(第 1 回合基準) |
| 第一層落空率 d=3 | 必死(只能取 3 = 殘窗) | 不保護(失敗約 96%) |
| 第一層落空率 d=4 | 21% | **50%**(候選 3 被佔的機率 4/8) |
| 第一層落空率 d=5 / 6 / 7 / 8 以上 | 7.1% / 1.4% / 0 / 0 | 21% / 7.1% / 1.4% / 0 |

新規則下救不回的損失,約 83% 集中在 d=3 和 d=4,這是目標下限 3、每次只剩 4 個候選造成的結構限制,調保護參數壓不下去。「5~8%」請改成約 20%,並以實測的「等不到」重抽占比為準。

## Q2 撞窗損失以命計(給 RD)

撞窗損失 = 最後一個窗口結束原因為「倒數走過」的命數 ÷ 至少開過一次窗的命數。分母排除三種命:以「錯色消失」結束的、以「局結束」結束的、在窗口開著時被「續命重設」的(後者算判斷指標三)。「被抓取未捕捉」不算這一命結束,後面會接「放下後重開」;重抽錯失照同樣口徑,分子改取「網重抽換掉」與「從未開窗」。

| 窗口結束原因 | 分子 | 分母 |
|---|---|---|
| 捕捉 | 否 | 是 |
| 倒數走過(為這一命最後一個窗口) | 是 | 是 |
| 網重抽換掉 | 否(算重抽錯失) | 是 |
| 續命重設,窗口已過 | 看前一個窗口的原因 | 是 |
| 續命重設,窗口開著 | 否 | 排除 |
| 錯色消失 / 局結束 | 否 | 排除 |
| 被抓取未捕捉 | 不算結束 | 不算結束 |

## Q3「結束時是否有同色其他顆可達且剩餘續命更少」

這一欄對應撞窗損失的假設(B3)。模型把「窗口過了」全算成手忙不過來,但「讓 A 過去等 B」是故意放掉,會灌高實測撞窗損失、把係數 0.65 校偏。和現有「開窗那一刻手是否空的」「這 1 秒內拖曳時長」並用,就能分出故意放掉和手忙錯過;它同時也是判斷指標一最常見的形式,所以同意記,成本是每次窗口結束多一個是非值。

| 欄位組合(窗口結束原因為倒數走過) | 分類 | 用途 |
|---|---|---|
| 手空 + 同色有更少續命的可達顆 | 故意放掉 | 判斷指標一,從撞窗損失分子扣除 |
| 手忙(這 1 秒拖曳 > 0.5 秒) | 手忙錯過 | 撞窗損失 |
| 手空 + 沒有這樣的顆 | 反應慢 | 手速指標 |

「可達」照企劃的定義:顯示倒數 ≥ 目標。末命保護會替故意放掉的後果兜底,解讀時要當前提,這點同意企劃。
