## 數值 spec-review 第 2 回合

修正 r1 兩處: 踩拍分類「不踩拍」分界 < 45% 改 < 50%; 開局血量由不動改為 50 → 60。

### Q1 「主動對拍」與「更累」判準
亂按時時間差在 ±200 毫秒均勻分布, 四分位距 200、抓起與送進網踩拍率 35%; 一局約 100 個計次節點時標準差約 4.8%, 45% 只高 2 個標準差容易誤判, 分界提高到 50%(約 3 個標準差)。以四分位距為主讀數: 音訊延遲只讓分布偏移不讓它變寬。

| 讀數 | 亂按基準 | 門檻 | 推算 |
|---|---|---|---|
| 時間差四分位距(各節點、以中位為中心、非靜音局) | 200 毫秒 | ≤ 130 算有集中; ≤ 90 算熟練 | 大部分踩拍對應標準差約 67、四分位距約 90 |
| 抓起 + 送進網踩拍率 | 35% | ≥ 50% 算在對拍; 「不踩拍」改 < 50% | 35% + 3 × 4.8% |
| 主動對拍(綜合) | — | 上兩項成立且踩拍率隨局數上升 | |
| 更累: 網在場時間(同階段、第 2 局起, 大部分踩拍局對不踩拍局) | 預算假設多 8% | 多 > 15% 算變累 | |
| 更累: 送錯彈回率 | | 多 > 3 個百分點或相對多 > 50% | |
| 更累: 放下到下一次按下中位 | | 多 > 0.1 秒(輔助) | 刻意等拍 |
| 靜音局 | | 靜音占存活 > 50% 的局另列 | |

### Q2 踩拍改給連續數 +1 或分數倍率
建議維持現行「回血 + 溢出換分 2 分」: 血不滿換存活、滿血換分數, 新手熟手都有收益。改連續數: 新手失去約 +19% 存活; 熟手階段 1~4 很少斷連, 常在加成上限, 多加的連續數一碰上限就沒用。

| 方案 | 新手時長(不踩 / 大部分) | 熟手時長 | 熟手踩拍分數收益 / 局 |
|---|---|---|---|
| 現行 | 159 / 190(+19%) | 約 210~230(差距 0~8%) | 約 +1040(占總分 26%) |
| 連續數 +1 | 159 / 159 | 不變 | 約 +530 |
| 分數倍率 | 159 / 159 | 不變 | 可調, 新手存活收益消失 |

### Q3 開局血量 50 → 70 或危險線 40 → 30
選提高開局血量但取 60: 新手首局第一次按下約慢 5 秒(扣 9 血)加起伏約 ±6, 起始要比危險線高 20 才不會開局就響; 典型新手約 76 秒回滿, 多給的變溢出, 時長幾乎不變。危險線降 30 只讓音效晚響, 指標 5 仍以 40% 計, 慢新手照樣不及格且口徑脫鉤。

| 項目 | 現行 50 / 40 | 開局 60 | 開局 70 | 危險線 30 |
|---|---|---|---|---|
| 慢新手(每顆 3.0)首次進危險 | 10~15 秒 | 約 65 | 約 78 | 約 65(≤ 30) |
| 慢新手死亡 | 約 90 | 約 96 | 約 102 | 約 90 |
| 慢新手「首次 ≤ 40% ≥ 單局 55%」 | 17% 不過 | 68% 過 | 76% 過 | 17% 不過 |
| 典型新手首次 ≤ 40 / 死亡 | 142 / 160~165 | 不變 | 不變 | 147 / 不變 |
| 典型新手開局回滿 | 約 76 | 約 50 | 約 37 | 約 76 |
| 熟手回滿 / 時長 | 約 31 / 不變 | 約 22 / 不變 | 約 13 / 不變 | 不變 |
| 熟手多出溢出 | — | +10 點(+20 分) | +20 點 | 0 |

建議: 開局 60; 危險線維持 ≤ 40 進、≥ 50 出; 開局回滿預測改新手約 50、熟手約 22 秒。
