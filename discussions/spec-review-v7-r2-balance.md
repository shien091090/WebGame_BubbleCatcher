# 第 2 回合: 製作人追問 Q1~Q3

**Q1. 開局第 0 秒預放 2 顆 + λ0 0.22**

開局預放 2 顆只在開頭多給一段工作量: 熟手 3.1 秒, 新手 5.1 秒; 空場時間剛好少掉這麼多, 到新手開始過載(第 45 秒後)早已消化完, 首次命 ≤ 2 不受影響。不建議預放 3 顆: 新手約 7.6 秒才清完, 第 1 秒生成的那顆第 13 秒到期, 新手約第 12.7 秒才處理到, 開局就可能過期。

| 項目 | 只調 λ0 0.22 | + 預放 2 顆 | + 預放 3 顆 |
|---|---|---|---|
| 熟手前 60 秒空場占比 | 47% | 42% | 39% |
| 新手前 60 秒空場占比 | 16% | 7% | 3% |
| 新手首次命 ≤ 2 | 約 75 秒 | 約 75 秒 | 約 75 秒 |
| 階段 1 捕捉率 新手 / 熟手 | 0.95 / 1.0 | 0.96 / 1.0 | 0.93~0.96 / 1.0 |
| 開局平均生成間隔(有 5 秒上限) | 約 4.3 秒 | 同左 | 同左 |

企劃說的 6.7 秒是名目值, 實際被最大生成間隔截成約 4.3 秒。熟手空場 42% 仍符合 3b。

**Q2. 區域放進內圈內**

對模型沒有漏洞, 但要補一條規則、接受一項新成本。繞路漏洞不存在: 拖曳中不跟其他氣泡碰撞, 內圈本來就是自由通道, 只要窄道或障礙在「染色區到目標網」連線上, 走內圈也繞不開。

| 項目 | 數字 | 依據 / 影響 |
|---|---|---|
| 生成點一開始就與區域相交的比例 | 染色 / 賦形(相交距離 50)每塊約 13%; 洗除(半徑 40)每塊約 18% | 50² ÷ 140²、60² ÷ 140² |
| 規則沒寫的後果 | 起點在區上的氣泡 | 建議明寫「抓起那一刻已相交不算擦過」 |
| 路徑難度隨起點變化 | 起點落在洗除區旁的比例約 20~30% | 單顆處理時間起伏約 ±0.2 秒, 錯擦率要按起點分組 |
| 內圈容量 | 不變 | 區域是地面 |

埋點補: 抓取時氣泡是否已與某區域相交(記區域 ID), 對應 D3、D5。

**Q3. 覆蓋拆有意 / 失誤後的指標 4, 以及過載會不會再崩**

指標 4 分子改「錯擦 + 失誤覆蓋」。失誤覆蓋 = 覆蓋之後同一顆在捕捉前又擦回原值; 或這顆條件不符彈回而不符的正是被覆蓋的那項。門檻改「每次捕捉平均多花的時間 ≤ 0.3 秒」。

| 類別 | 每次代價 | 門檻 |
|---|---|---|
| 錯擦 | 約 1.5 秒 | 單獨 ≤ 0.20 |
| 失誤覆蓋 | 約 0.5 秒 | 不單獨設 |
| 合計 ÷ 捕捉 | | 0.05~0.25 |
| 加權代價(1.5 × 錯擦 + 0.5 × 失誤覆蓋)÷ 捕捉 | | 主門檻 ≤ 0.3 秒 |
| 有意覆蓋 | 0 | 只描述 |

過載會不會再崩: 預期 v7 不會像 v6 崩到 0(v6 崩是因為能抓的前提是開窗); 預測死前 30 秒產能只比積壓期降 10~15%; 剩下風險是內圈 160 裡擠 13 顆以上時抓錯、按住沒拖變多; 崩盤段估計約 36 秒先不改。要看: 積壓期處理率死前 60 秒每 10 秒對照場上數(場上 ≥ 13 顆時低 > 15% 就推翻 D11); 按下「距上次放下的間隔」死前 30 秒 vs 之前(中位變長 > 0.3 秒); 按住未拖與同顆重複抓取依場上數分組; 最後一次滿命到死亡 < 25 秒則改用實測重算斜率。

相對 r1 修正: 指標 4 門檻改加權代價 ≤ 0.3 秒 + 錯擦單獨 ≤ 0.20。其餘不變。
