## 推算過程
0. 第 11 輪 JSON 校正: 實際跑的斜率是 0.025(第 3 關前段每秒扣血 5.573 = 5.2 + 0.025 × 15)。單局 284.1 秒、第 3 關停留 114.2 秒; 第 3 關每秒觸發 0.482 次、每次應得 12.44、實得 12.15、實得收入 I = 5.85; 進出關血量第 1 關 60 → 97.6、第 2 關 97.6 → 91.5; 第一次滿血第 16.1 秒; 最後滿血到死 69.7 秒。各段每秒淨血(含溢出): 1 前 +1.59、1 後 +1.95、2 前 +1.69、2 後 +0.21、3 前 +0.63、3 後 −1.19。推翻「第 3 關收入 4.0~4.5」「第 3 關前段斷崖」, I 只有 1 局樣本。
1. 第 3 關存活公式(a = I − 5.2, s = 斜率, H = 進關血量, 回滿後 100): I > 5.2 時存活 = a ÷ s + √(2H ÷ s); I ≤ 5.2 時 = [a + √(a² + 2Hs)] ÷ s。第 11 輪 115.4 秒驗算其實是用 H = 100。代入: 高檔 I = 5.85 → 99.4 秒 → 單局 269.3(斜率 0.040 時 256.9); 熟手 I = 4.0~4.5 → 50.0~60.2 秒 → 219.9~230.1; 邊緣型反推 I = 3.57~3.89 → 213~218; 第 3 關完全不動作 I = 0 → 18.2 秒, 所以 170~188 結構上不可能、188~206 要 I < 3.0 實際也不會有。第 2 關門檻每秒淨血 ≥ −B2 ÷ 96(−1.15 / −1.20 / −1.25); 後備扣血 4.9 時門檻約 −1.38。

## 抄錯 / 算錯逐條
1. 【口徑錯】telemetry 第 307 行「熟手第 3 關前段約 −0.7」「邊緣型 −1.3~−1.6」其實是第 3 關第 0 秒瞬時淨血(I − 5.2), 前段平均要再扣 0.032 × 1920 ÷ B3(128 BPM 時 −0.48): 熟手前段平均 −1.18~−1.68、邊緣型 −1.79~−2.11; 第 210 行拿 −0.7 當前段點估計相減有固定 −0.48 偏差。

5. 【小】第 1 關無壓力三處不一致: spec 第 512 行與待定 2「第 16~30 秒起滿血, 約 56~67 秒」, 16 秒起應為 56~70; telemetry 第 317 行仍寫 19~30; 實測 16.1 秒。
