# 捕泡手 v18 改版前數值預算(spec 第 15 版前)

結論先講: v18 改成「一批清完才出下一批」以後, 氣泡供給由玩家自己的速度決定, 不再受出批節奏限制。存活時間只看「每秒回血收入 − 每秒扣血」, 舊的扣血值(1.8~3.3)對所有人都是正收支, 必須整體上調。另外有兩個會卡死或讓玩家撞牆的組合, 要先補規則: 自動換位抽到的條件可能沒有氣泡能滿足; 第 3 關跳網如果連條件一起換, 已沾色的氣泡會卡住。

讀取的檔案: decisions.md、archive/spec.v14.md、archive/telemetry.v14.md、feedback/round-8-logs/ 兩局(A 局 080524、B 局 153239)

### 2. 被實測推翻的假設
1. 「新手不踩拍」被推翻: 老闆第 1 局送進網踩拍率 57%(亂按約 27~35%), 第一次沾上 85%(亂按 44%); 每顆回血 9.07, 不是假設的 6.2。這是 v16 低估時長的主因(新手預測 162 實測 199, 中間預測 211 實測 250, 低估 19~23%)。
2. 兩項條件多花 0.55 秒被推翻: 實測 0.64~0.80, 平均約 0.72。
3. 扇區讓一項條件網在場時間降到約 1.18 秒被推翻: 實測 1.55~1.77。
4. 新手每顆處理時間低估: 第 2 關後段假設 2.36、實測 2.58。中間型與第 3 關收支大致成立。
5. 「按住先想」占 62% 偏低: 實測 76~91%。
6. 成立: 第 1 關沒有壓力; 清完一批 ≈ 0.3 + 顆數 × 每顆秒數。

### 3. v18 模型
一批循環 = 首按延遲 + 批間等待 + 這批每顆處理時間總和。每秒淨血 = 顆數 × [(1 − 沾錯率) × 每顆回血 − 沾錯率 × 沾錯扣血] ÷ [首按延遲 + 批間等待 + 顆數 × ((1 − 沾錯率) × 每顆處理時間 + 沾錯率 × 0.9)] − 每秒扣血。首按延遲 0.65 秒; 批間等待為最後一顆離場後第 2 個拍點, 平均 1.5 拍 = 0.90 / 0.78 / 0.69 秒; 沾錯從出手到消失約 0.9 秒。

碰網即收每顆省約 0.09 秒(0.05~0.13), 占 4~5%: 氣泡中心約 280 就碰牆(原本中位 328 才放開), 送進網時刻提早約 45~70 毫秒, 回程少約 48 像素(約 0.04 秒)。偏移補償要重校。

每顆處理時間(已扣碰網): 熟手一項 1.65 / 兩項 2.35 秒; 首局新手一項 1.80 / 兩項 2.65 秒; 不踩拍新手手速同首局新手。

關卡特色成本: 第 2 關地板輪轉(每 4.17 秒)碰到輪轉機率約 24%, 預告 1 拍時撞錯色新手約 30%、熟手約 15%, 沾錯率多 7% / 3.6%, 換算新手約 −0.39、熟手約 −0.22 血/秒。第 3 關跳網只換位置每顆多約 0.08 秒(約 −0.15 血/秒); 連條件一起換約每 15 秒卡住一顆, 卡在批尾擋住出批, 約 −0.5~−0.8 血/秒。

每顆回血(捕捉 6、踩拍 2、整串 2): 熟手 10.95 / 11.07 / 11.4; 首局新手 9.6 / 10.6 / 10.4; 不踩拍新手 7.66 / 7.94 / 8.0(第 1 / 2 / 3 關)。沾錯率: 熟手 2% / 6.5% / 3%; 首局新手 3% / 12% / 5%。

每秒收入(第 1 關前 / 後、第 2 關前 / 後、第 3 關): 熟手 5.28 / 5.49 / 4.80 / 4.69 / 4.99; 首局新手 4.27 / 4.42 / 4.03 / 3.91 / 4.09; 不踩拍新手 3.40 / 3.52 / 2.98 / 2.89 / 3.13。驗算每秒捕捉熟手第 3 關 0.44、新手第 2 關後段 0.38, 與 v14 實測對得上。

### (2) 無解與無限延續
1. 自動換位抽到沒人能滿足的條件(會出事): 剩一顆單色氣泡時隨機新網符合機率約 1/4, 平均換 4 次約 9.6 秒, 接近壽命, 下一批出不來, 約 −40 血。必須規定: 換位後的新條件只從場上至少一顆能滿足的條件裡抽。
2. 第 3 關跳網連條件一起換(會出事): 會把正在送的已沾色氣泡變成不能滿足, 卡在批尾擋住出批, 平均 14.8 秒超過壽命。建議跳網只換位置、條件不變; 只有在卡住狀態下才同時換成能滿足的條件。
3. 第 2 關輪轉那一刻氣泡正壓在地板上(有洞): 約一成的輪轉會讓氣泡被輪轉過來的地板染上而沾錯消失。要規定: 輪轉那一刻已相交的不算擦過。
4. 無限延續: 不存在。按住凍結壽命時扣血照走; 第 3 關扣血一直上升, 理論最強玩家約第 3 關第 197 秒死, 單局上限約 367 秒。
5. 故意沾錯甩掉氣泡: 划不來(每顆回血 + 沾錯扣血 > 扣血 × (每顆處理時間 − 0.9), 最壞 13 > 9.6)。
6. 同一批自己過期: 很少。首局新手每批 6 顆時最後一顆約冒出後 10.4 秒被按下; 7 顆會到 12.6 秒, 所以每批最多 6 顆。

### (6) 踩拍回血要不要調
要調。照現行 4 / 2 / 4, 熟手每顆回血裡踩拍和整串占 62%, 不踩拍收入只剩 0.58 倍, 等於把「沒踩拍不罰」做成實質門檻(不踩拍新手約 105 秒死在第 1 關末)。改 6 / 2 / 2 後占比約 46%, 不踩拍新手撐到約 129 秒。送進網判定窗維持 ±80 毫秒, 下輪送進網踩拍率比 v14 掉超過 10 個百分點(A 型 < 47%、B 型 < 70%)再放寬到 ±0.18 拍; 送進網偏移補償 −20 改 0, 依首輪實測中位重校。
