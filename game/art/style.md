# 捕泡手 美術規格(style.md)

RD 只需讀本檔。`art.js` 掛在 `window.Art`, 非 ES module。art.js 內含中文字串, `index.html` 必須有 `<meta charset="utf-8">`, 否則 file:// 下所有文字變亂碼。

本版(規格 v13: 音樂拍子、踩拍回血、命改血條、靜音、預備拍)相對 game-v12 的變動:
- **新增 `drawBeatCue(ctx, state)`**: 拍子提示(內圈邊線隨拍發光 + 從外往內收的收攏環), 需要 RD 接
- **新增 `drawCountIn(ctx, state)`**: 預備拍(內圈中央「預備」+ 剩幾拍的大數字 + 4 顆點), 需要 RD 接
- **新增 `drawBeatFx(ctx, state)`**: 踩拍回饋(動作處的拍子粉星芒), 需要 RD 接
- **新增 `drawChainFx(ctx, state)`**: 整串回饋(網上的雙層大星芒 + 一排菱形), 需要 RD 接
- **新增 `drawMuteButton(ctx, state)`**: 靜音按鈕(兩種狀態), 需要 RD 接; 新增 `Art.layout.muteButton`
- **`drawHud` 改畫法 + 改 state**: 命從 5 顆愛心改成連續血條(0~100), 新增危險狀態、回命 / 扣命那一段、溢出轉分數提示; 欄位見物件表。`hp` 改傳 0~100, `hpMax` 預設改 100
- `drawGuidePage`: 改成 7 頁(`page` 1~7), `Art.layout.guide.pages` = 7。第 2 頁拿掉命; 第 5 頁改三格血條; 新增第 6 頁「對上拍子」; 原第 6 頁「結束」移到第 7 頁並改畫血條掉到空
- 色票新增 `beat`(拍子粉)、`hp`(血條一般填色)
- 其他函式(`drawBackground`、`drawInnerRing`、`drawPaintZone`、`drawShapeZone`、`drawNet`、`drawBubble`、`drawClearFx`、`drawStageNotice`、`drawPauseButton`、`drawPauseMenu`、`drawTitleScreen`、`drawInputSelect`、`drawEndScreen`)原樣保留, 函式名與 state 不變
- 沒有刪除任何函式

## 邏輯畫布尺寸

1280 × 720(`Art.canvas.width / height`)。所有座標皆為此邏輯解析度。

## 形狀語言

圓形為主、圓角面板; 能拿起來的東西(氣泡)是立體的球: 漸層 + 高光 + 落影; 地上的東西(內圈、染色區、賦形區、網)一律平塗、無影; 有色 = 實心, 無色 = 空心灰白框; 預告中 = 虛線; 新出場 / 剛改變 = 四個白色角框; 外擴線環 = 單顆物件的屬性變了 / 被收下, 填滿地面的亮光 = 清場; **拍子 = 拍子粉, 「往內收」的環 = 拍子快到了, 尖刺外放的星芒 = 對上拍子(星芒越大、層數越多 = 份量越大)**。

## 理念落實

- P0 辨識度先於好看: 五種場上物件長相各不同(氣泡立體球、染色區平色池 + 水滴、賦形區灰藍平地 + 空心形狀、亮網網格 + 色框 + 外光、不亮槽位細灰虛線); 新增的拍子相關元素全部用全場唯一的拍子粉, 回饋一律用星芒(不是圓), 不跟既有物件撞長相; 命的一般 / 危險兩態用灰藍 / 紅 + 脈動外框分開
- P1 視覺權重跟著決策迫切度: 亮著的網與氣泡仍最搶眼; 拍子提示每拍都出現, 所以壓低: 邊線發光只在拍點後 0.3 拍內、收攏環細線半透明, 都畫在內圈邊上、不進到氣泡與區域所在的地面; 踩拍回饋中心挖空, 不蓋住正在拖的氣泡; 整串回饋只出現在剛收下、已熄滅的槽位上(那裡已沒有決策資訊)
- P2 規則上存在的東西畫面上就存在: 拍子時鐘看不到, 用拍子提示畫出「這一拍」與「下一拍還多遠」; 預備拍畫出剩幾拍; 危險狀態(≤ 40 進、≥ 50 出)畫在血條上, 並在 40 處留一道刻痕; 溢出換分畫出滿格帽 + 分數旁的「+N」; 靜音 / 有聲兩態各有外觀; 沒踩拍依規格不罰, 所以不畫任何失敗記號
- P3 一個意義一種長相: 拍子粉只代表拍子(提示、預備拍、踩拍回饋、整串回饋、踩拍回的那段命), 回命那段的顏色直接告訴玩家這段命是捕捉(白)還是拍子(粉)給的; 紅只代表危險 / 損失(命危險、扣命殘影); 往外擴的線環仍只給「屬性變了 / 被收下」, 拍子提示刻意用往內收的環、踩拍回饋刻意用星芒, 不借用線環; 說明頁的命、拍子提示、踩拍回饋直接呼叫遊戲內畫法
- P4 關鍵區分至少兩條通道: 捕捉(白線環 + 勾)vs 踩拍(粉 + 星芒)vs 整串(粉白雙層大星芒 + 菱形列)vs 清場(地面亮光 + 中央字)— 每組至少差顏色與形狀兩條; 命一般 vs 危險 = 顏色 + 外框脈動 + 「命」字變紅; 靜音 vs 有聲 = 按鈕反白 + 喇叭打叉 / 聲波; 拍點上 vs 兩拍之間 = 邊線發光 vs 收攏環在半路
- P7 每個元素要掙得版面: 血條不配數字(規格只要求看得出占上限多少, 數字不改變決策); 踩拍回饋不配字(不寫「+2」, 命那段變粉已說明); 拍子提示不加節拍器、小節計數之類的第二套; 預備拍的「預備」兩字保留(拿掉測試: 只剩一個大數字時, 會被讀成分數或倒數計時的別種東西)
- P8 動態是溝通: 收攏環是全場唯一常駐的動態, 它在說「下一拍還多遠」; 邊線發光說「就是這一拍」; 其餘拍子元素只在事件當下出現
- P13 事件要排隊: 送進網的節點若同時是整串, 只畫整串回饋(不再疊一個踩拍回饋); 整串在網上、清場在內圈正中, 兩處不重疊; 預備拍期間場上沒有氣泡與亮網, 中央數字不跟其他東西搶
- P15 回饋強度和份量成正比: 捕捉(單條白線環)< 踩拍(半徑 72 粉星芒)< 整串(半徑 132 雙層星芒 + 菱形列)< 清場(整片內圈); 在命那頭同步分級: 捕捉段白、踩拍段粉、整串段粉且外光加粗
- P16 每個狀態都要有外觀: 命 = 一般 / 危險 / 回命中 / 扣命中 / 溢出; 靜音按鈕 = 有聲 / 靜音 × 一般 / 滑鼠停留; 拍子提示 = 拍點上 / 兩拍之間(收攏環位置連續變化, 本身就是過渡狀態的預告)
- P17 進度類資訊, 圖形與數字分工: 氣泡壽命環照舊畫 12 秒總剩餘比例(氣泡上無數字); 血條無數字, 依邊界畫總量, 另用 40 刻痕給「離危險還多遠」; 收攏環畫「離下一拍還多遠」, 不畫小節或拍數
- P18 重要資訊不能只存在一瞬間: 回命 / 扣命的亮段消失後, 血條長度本身留著結果; 溢出換得的分數留在 HUD 分數裡; 清場分同理; 結束畫面再列存活時間與分數
- P19 資訊貼著物件: 踩拍回饋畫在動作發生處(抓起與沾上在氣泡上、送進網在網上); 整串回饋畫在剛收下的網上; 溢出的「+N」貼在分數旁、滿格帽貼在血條滿的那頭; 拍子提示畫在玩家視線所在的內圈邊上, 不放在 HUD 角落
- P21 示意圖選分岔例子: 第 1 頁擦 A 再擦 B 仍是 A; 第 2 頁透明放上亮網、色 A 放不亮槽位都回內圈; 第 3 頁兩種「之後」位置不同、一種同色一種換色; 第 4 頁兩顆環同起點、只有按住的不走; 第 5 頁左格「什麼都沒做命也短了」(分開「命只在出事時變」的誤解); 第 6 頁下排同樣的抓起、只差在兩拍之間, 結果只差「沒有回饋、命沒多」, 不出現失敗記號(分開「沒對上會被罰」的誤解)

## 物件表

所有函式簽章固定 `(ctx, state)`, 每個函式內部自行 save / restore。state 內沒寫預設值的欄位為必填。「未出場」的區域不呼叫; 不亮的槽位照樣呼叫(畫空槽)。

|---|---|---|---|
| 內圈外區域 | `drawBackground(ctx)` | 無 | 整面 bg 深色 |
| 內圈 | `drawInnerRing(ctx, state)` | 無(state 可省略) | 固定: 圓心 (640,360) 半徑 210 的亮一階平面圓 + 3px 邊線 |
| **拍子提示(新增)** | **`drawBeatCue(ctx, state)`** | `phase`: 0~1, 距上一拍經過的比例(= (拍子時鐘秒數 ÷ 0.4) 的小數部分; 0 = 正在拍點上, 接近 1 = 下一拍快到)。預備拍期間照樣給(時鐘從第 −4 拍起算, 例: 預備拍開始那一刻 phase = 0) | 拍點上(phase 0~0.3): 內圈邊線變拍子粉並發光, 0.3 拍內退回原色。兩拍之間: 一圈拍子粉細線(收攏環)從半徑 237 往內收, phase → 1 時收到內圈邊線上 = 下一拍; 越接近越亮。暫停時 RD 停住 phase(畫面凍結)。靜音照常畫 |

### 與理念的張力(交製作人決定)

- 收攏環是全場唯一每秒 2.5 次、永遠在動的元素(P8 候選)。保留理由: 規格要求「能從畫面預判下一拍」, 只有拍到才閃的邊線做不到預判。試玩若嫌吵, 可只留邊線發光(RD 傳 phase 時不需要改, 告訴美術改成參數)
- 每次回 2 點命在 182 像素的條上只有約 4 像素, 美術把亮段至少畫成 6 像素寬並加外框, 是稍微誇大的回饋(不是讀數)
- 氣泡的四種節點踩拍狀態沒畫在氣泡上(P2「規則上存在的東西畫面上就存在」): 一顆氣泡還有沒有機會整串, 玩家看不到。理由: 說明頁刻意不教整串、留給玩家自己發現; 每顆氣泡多一排記號違反 P7。若試玩顯示玩家不知道整串是怎麼來的, 可在氣泡壽命環下緣加小粉菱形(與整串回饋同一個記號)
- 舊有張力沿用: 預告條部分重述區域預告、換位掃光每次都播、「已鎖定」收縮環可能頻繁、清場的「清空 +50」字樣、波次冒出同時多顆在彈
