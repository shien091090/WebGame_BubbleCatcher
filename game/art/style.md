# 捕泡手 美術規格(對應 spec v14)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文字串在 file:// 下會變亂碼。
> art.js 以一般 `<script>` 載入, 產生全域 `window.Art`。全部 Canvas 2D 幾何, 無外部資源。

## 1. 邏輯畫布尺寸

1280 × 720(`Art.canvas`)。內圈圓心 (640,360) 半徑 210; 網牆正八邊形每邊中點距圓心 300、頂點約 324.7(頂點在 22.5° + 45° 倍數)。

**一組函式畫三套**: 幾乎每個 draw 函式的 state 都有 `level`(1 / 2 / 3, 缺省 1), 換關時 RD 只要把 `level` 換成新關即可整套換風格。

## 3. 形狀語言

可拿起的(氣泡)= 立體(放射漸層 + 高光 + 反光弧 + 常駐落影 + 壽命環); 場景的(地板、內圈)= 平塗、無影、無高光; 每關只換「皮」(背景、地面紋理、網牆線型、色組、拍子提示造型), 不換「骨」(上面這套分類手法)。第 1 首圓潤柔光、第 2 首霓虹雙線發光、第 3 首硬角分節。

## 4. 理念落實

- P0 辨識度先於好看: 三套風格只換皮; 「氣泡立體 vs 地板平塗」「透明空心 vs 有色實心」「亮邊粗發光 vs 不亮細暗」三條分類線三關都不變。
- P1 視覺權重跟著決策迫切度: 亮著的網(粗 + 條件色 + 外光 + 內側柔光)與操作中的氣泡是全場最亮; 拍子提示是細線半透明、背景無動態。
- P2 規則上存在的東西畫面上就存在: 已鎖定擦過也有回饋(灰標籤 + 鎖頭 + 內收虛線環); 預備拍中不生效的新關地板用「虛線 + 未填滿」畫出來。
- P3 一本字典: 形狀路徑(圓 / 方 / 三角)氣泡、網條件、賦形地板、沾上標籤共用一個函式; 白 = 捕捉 / 凍結; 灰 = 已鎖定; 角框 = 剛出現; 虛線 + 由中心長大 = 還沒生效; 半透明 = 彈回中; 拍子色只代表拍子。換關帶過的那一顆與舊亮網一起用舊關色組(`paletteLevel`)。
- P4 關鍵區分兩條通道: 沾上 vs 已鎖定 = 顏色(有色 / 灰)+ 圖樣(色塊 / 鎖頭)+ 環的方向(外擴實線 / 內收虛線); 氣泡 vs 地板 = 立體有影 vs 平塗無影 + 尺寸位置(地板固定、氣泡會動)。
- P7 每個元素掙得版面: 網條件只畫有列的項目(顏色靠亮邊本身, 有形狀條件才加中央符號); 歌曲進度不寫數字; 拍子提示沒有字。
- P9 以最混亂那刻驗收: 沾上回饋改成浮在氣泡正上方的標籤(白框 + 深色外描, 寫出沾上的色或形), 以滿場 10 顆氣泡 + 多個回饋同時出現的截圖驗過一眼找得到。
- P13 事件排隊: 同一顆氣泡同時沾色又賦形時, 兩個標籤用 `stack` 往上疊, 不重疊; 換關提示與預備拍數字分上下兩處。
- P15 回饋強度和份量成正比: 捕捉(白細環 + 勾)< 踩拍第 1 級(兩側 1 組音波弧 + 1 個拍點)< 第 2 級(2 組)< 第 3 級(3 組 + 外環 + 白弧)< 整串(實心閃光 + 20 根音浪條 + 外白環)< 清場(整片內圈亮起 + 「清空」)。級數同時走「弧組數」與「下方亮幾個拍點」, 可數。
- P17 進度圖形與數字分工: 壽命環無數字, 照規格畫總剩餘比例; 歌曲進度只有圖形。
- P18 重要資訊不只一瞬間: 回命 / 扣命除了動作處回饋, 命條上也留 0.6 秒亮段。
- P19 資訊貼著物件: 沾上 / 已鎖定標籤、踩拍拍點都貼在那顆氣泡上、跟著它走; 網條件就在亮邊上。
- P21 示意圖選分岔例子: 說明第 1 頁三個時刻讓「擦過 B 還是 A」與「會變成 B」畫出不同結果; 第 2 頁放開點刻意放在內圈與亮邊之間, 讓「要壓到牆上」的錯誤理解看出不同。

### 說明頁內容(第 1 首風格)

1. 內圈 + 染 A、染 B; 一顆氣泡三個時刻(透明 → 擦過 A 變 A → 擦過 B 仍是 A), 箭頭到擦過 B 為止, 指標按著最後那顆; 無網牆。
2. 三格網牆 + 內圈, 右邊亮、要色 A。① 色 A 放開在內圈與亮邊之間 + 勾; ② 透明放同一處(虛線圈 = 放開點)→ 虛線彎箭頭回內圈; ③ 色 A 往不亮的左邊放 → 回內圈。只畫放開前最後一小段箭頭, 不畫扇區, 無命。
3. 左: 右邊亮色 A、色 A 氣泡正往那裡放。→ 右兩格「或」: 左下邊亮色 A / 上邊亮色 B, 原本那邊都熄滅且都不在隔壁。無路線。
4. 三格時間序, 每格兩顆透明氣泡放大; 被按住那顆環一直滿(白), 另一顆 滿 → 少一段 → 再少一段。無命、無網、無區域、無標注。
5. 三格, 每格左上有命(都沒滿)。左: 同一條命前後兩刻, 後一刻較短; 中: 色 A 送進亮著色 A 的網 + 勾, 命多一段白色亮段; 右: 環走完的氣泡 → 原位變空, 命少一段紅色亮段。
