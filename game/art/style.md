# 捕泡手 美術規格(style.md)

RD 只需讀本檔。`art.js` 掛在 `window.Art`, 非 ES module。art.js 內含中文字串, `index.html` 必須有 `<meta charset="utf-8">`, 否則 file:// 下所有文字變亂碼。

本版(v3 規格)相對 game-v2 的變動: 網刪除冷卻、改顯示目標數字; 氣泡右上角「下次續回秒數」小圈改為下緣「剩餘可續次數」兩顆圓點, 倒數最低顯示 1; 左上 HUD 加「命」字; 暫停按鈕「暫停」字樣移到按鈕上; 說明 5 頁重畫。函式名與既有 state 欄位不變, 刪除與新增的欄位見物件表標註。

## 邏輯畫布尺寸

1280 × 720(`Art.canvas.width / height`)。所有座標皆為此邏輯解析度。

## 形狀語言

圓形為主、圓角面板、扁平填色; 可互動 = 實線亮框; 數字壓在遊戲物件上一律白字黑描邊; 「還剩幾次」用可數圓點, 不用數字。

## 理念落實

- P0 辨識度先於好看: 四色靠色相 + 明度拉開; 氣泡閒置 / 拖曳 / 彈回、剩餘可續 2 / 1 / 0 各有獨立外觀, 靜止截圖就分得出
- P1 視覺權重跟著決策迫切度: 本作的決策核心是「網上的數字 vs 氣泡上的數字」, 網中央的目標數字是全場最大的字(34px, 深色圓盤托底); 快過期用全畫面唯一的紅色倒數環; 捕捉 / 錯色的勾叉貼在網的右上緣, 不蓋住捕捉後剛換上的新數字
- P2 規則上存在的東西畫面上就存在: 目標數字、剩餘可續次數、彈回中不可抓(半透明)、續命成立(本體泛白 + 白環外擴)、無效雙擊(圓點左右晃 + 紅框)、網換數字(targetFx 白環)都有外觀
- P3 一個意義一種長相: 數字只代表「秒 / 目標秒」, 次數改用圓點避免讀混; 紅 = 損失、白勾 = 成功; 虛線空圈 = 說明頁裡「之前在這裡」, 半透明只保留給遊戲內的彈回中; 說明頁的網、氣泡、命、結束畫面直接呼叫遊戲內畫法; HUD 與說明同稱「命」
- P4 關鍵區分至少兩條通道: 老闆已明言 prototype 不考慮色弱, 四色只靠色相 + 明度; 語意不同的結果走兩條通道: 捕捉(白色 + 勾)vs 錯色(紅色 + 叉)vs 數字不符彈回(白色虛線環、無符號)
- P7 每個元素要掙得版面: 網上不寫顏色名、不寫「目標」; 氣泡上的次數不寫字; HUD 只留「命 / 分數 / 連續」兩字內小標, 時間只帶「秒」; 暫停按鈕的「暫停」字樣是規格明文要求
- P13 事件要排隊: 本作沒有文字橫幅; 事件回饋全部貼在發生的網或氣泡上且 0.3~0.6 秒自己淡掉
- P18 重要資訊不能只存在一瞬間: 扣命閃光之後空心愛心常駐; 分數與存活時間常駐 HUD, 並在結束畫面再列一次
- P19 資訊貼著物件: 目標數字畫在網中央、倒數與剩餘次數畫在氣泡本身; 錯色叉叉畫在那張網上
- P21 示意圖選分岔例子: 第 2 頁錯色的氣泡數字刻意等於那張網的數字(5 = 5), 看得出扣命是因為顏色不是數字; 第 3 頁左右兩格都用同一張網 6、都保留滿格命, 只差氣泡數字 8 / 6, 分開「錯色扣命」與「數字不符只彈回」; 第 3 頁右格對照黃泡 9 → 7 而抓著的綠泡 6 → 6; 第 4 頁兩次雙擊前的數字一低(5)一高(9)

## 物件表

所有函式簽章固定 `(ctx, state)`, 每個函式內部自行 save / restore。state 內沒寫預設值的欄位為必填。

| 物件 | 函式 | state 欄位 | 各狀態視覺差異 |
|---|---|---|---|
| 內圈外區域 | `drawBackground(ctx)` | 無 | 整面 bg 深色, 與內圈的亮一階地面對比, 不另畫 |
| 內圈 | `drawInnerRing(ctx, state)` | 無(state 可省略) | 固定: 半徑 200 的亮一階圓 + 3px 邊線 |
| 捕捉網(4 張, 每張呼叫一次)/ 網目標數字 | `drawNet(ctx, state)` | `x, y`: 中心; `color`: 0~3; `target`: 目標數字 3~10(null 不畫數字); `targetFx`: 換新數字回饋 1→0, 建議 0.4 秒, 捕捉重抽與開局抽數字時觸發(預設 0, **新增欄位, 需要 RD 接**); `hot`: 拖曳中且指標在這張網判定半徑內時 true(預設 false); `flash`: `'catch'`/`'wrong'`/`'bounce'`/null, 剛發生的判定; `flashT`: 0→1 演出進度, 建議 0.5 秒跑完, ≥ 1 不畫。**已刪除 `cooldown`、`cooldownMax`**(傳了也不看) | 固定外觀: 實線 5px 色框 + 亮網格 + 淡色底; 中央深色圓盤(色框)上白色大字目標數字。targetFx: 圓盤與數字放大 18% 後回原大小 + 白環外擴。hot: 外圈加 3px 白環。flash catch: 白環外擴 + 網右上緣白勾; wrong: 紅環外擴 + 網右上緣紅叉; bounce: 白色虛線環(無勾叉, 表示沒扣命)。捕捉時請同一幀就把 `target` 換成新數字, 勾畫在邊緣不會蓋到 |
| 氣泡 / 氣泡倒數 / 氣泡剩餘可續次數 | `drawBubble(ctx, state)` | `x, y`: 中心; `color`: 0~3; `timer`: 剩餘倒數秒(浮點); `renewCount`: **已續命**次數 0/1/2(欄位名與意義沿用 v2, 剩餘次數由美術自算 = 2 − renewCount); `mode`: `'idle'`/`'drag'`/`'return'`(預設 idle); `renewFx`: 續命成立回饋 1→0, 建議 0.4 秒(預設 0); `renewFailFx`: 無效雙擊(次數用完)回饋 1→0, 建議 0.3 秒(預設 0); `showRenew`: 是否畫剩餘次數圓點(預設 true, 遊戲內不必傳; 說明頁第 1~3 頁與標題用 false) | 本體: 色號實心圓 + 左上高光。倒數: 中央白字 = max(1, ceil(timer)), 畫面 12 → 1, 不出現 0(timer 歸零那幀請直接移除氣泡); 外圈倒數環長度 = timer / 12, 顯示 ≤ 3 時環變紅加粗。剩餘可續次數: 氣泡下緣兩顆圓點, 白實心 = 還能續、暗色 = 已用掉(2 = 兩白、1 = 一白一暗、0 = 兩暗)。mode drag: 放大 1.15 + 地面影子, 倒數凍結由 RD 停住 timer 即可; return: 整顆 45% 透明(不可抓)。renewFx: 本體泛白 + 白環外擴(保留 v2 的續命成立回饋, 剩 11.4 續回 12 數字不變時靠它); renewFailFx: 圓點左右晃 + 暗點紅框 |
| 命 / 存活時間 / 分數 / 連續數 | `drawHud(ctx, state)` | `hp`: 0~4(欄位名沿用, 畫面上稱「命」); `hpMax`(預設 4); `time`: 存活秒數; `paused`: 暫停中 true; `score`; `combo`: 0 時不畫; `hpFlash`: 扣命回饋 1→0, 建議 0.6 秒(預設 0) | 左上: 小標「命」+ 愛心, 實心紅 = 剩餘、空心灰 = 已失去; hpFlash 時剛失去那格紅框放大 + 紅色半透明。畫面上不出現「HP」。時間 `xx.x 秒`; paused 時字變灰 + 右側暫停符號。右上: 分數大字右對齊, 連續數在下一列 |
| 暫停按鈕 | `drawPauseButton(ctx, state)` | `hover`(預設 false) | 48 × 48 圓角方塊, 按鈕上半雙豎線、下半「暫停」字樣(都在按鈕框內); hover 時底變亮、框變白 |
| 暫停選單 | `drawPauseMenu(ctx, state)` | `hover`: `'resume'`/`'restart'`/`'quit'`/`'help'`/null | 「開」= 呼叫本函式(全畫面暗罩 + 中央面板); 「關」= 不呼叫。由上而下繼續(亮底)/ 重開 / 放棄(紅框紅字, 不可逆)/ 說明(隔一段距離) |
| 標題畫面 | `drawTitleScreen(ctx, state)` | `hover`: `'start'`/`'help'`/`'device'`/null; `device`: null/`'mouse'`/`'touchpad'` | 自帶背景。遊戲名 + 四色氣泡 + 開始(亮底)/ 說明 / 輸入裝置; 已選過裝置時按鈕字為「輸入裝置: 滑鼠 / 觸控板」 |

### 按鈕與判定矩形(`Art.layout`)

點擊判定請直接讀 `Art.layout`, 與畫面保證一致(矩形皆為 `{x, y, w, h}`, x/y 為左上角):

- `layout.inner` = {x:640, y:360, r:200}; `layout.bubbleR` = 20; `layout.netR` = 60
- `layout.nets[i]` = {x, y, color}: 建議網色 上黃(0)、右綠(1)、下藍(2)、左紫(3)
- `layout.hudLeft` {20,20,240,80}; `layout.hudRight` {960,20,220,80}; `layout.pauseButton` {1206,26,48,48}(中心 1230,50)
- `layout.pauseMenu.resume / restart / quit / help`
- `layout.title.start / help / device`
- `layout.inputSelect.mouse / touchpad`
- `layout.end.retry / toTitle`
- `layout.guide.close / prev / next`

### 繪製層級(由下而上)

1. `drawBackground`
2. `drawInnerRing`
3. `drawNet` × 4
4. 閒置與彈回中的 `drawBubble`
5. 拖曳中的 `drawBubble`(永遠最上層的遊戲物件; 拖到網中央時會暫時蓋住網上數字, 屬正常)
6. `drawHud`、`drawPauseButton`
7. `drawPauseMenu`(暫停時)
8. 標題 / 輸入裝置 / 說明 / 結束畫面各自整面重畫, 不需先畫遊戲畫面; 從暫停開說明時直接只畫 `drawGuidePage`
