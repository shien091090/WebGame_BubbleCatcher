# 捕泡手 美術規格(style.md)

RD 只需讀本檔。`art.js` 掛在 `window.Art`, 非 ES module。art.js 內含中文字串, `index.html` 必須有 `<meta charset="utf-8">`, 否則 file:// 下所有文字變亂碼。

## 邏輯畫布尺寸

1280 × 720(`Art.canvas.width / height`)。所有座標皆為此邏輯解析度。

## 形狀語言

圓形為主、圓角面板、扁平填色; 可互動 = 實線亮框, 暫時不可用 = 虛線暗框 + 半透明; 文字壓在遊戲物件上一律黑色描邊。

## 理念落實

- P0 辨識度先於好看: 四色靠色相 + 明度拉開; 每種狀態(網可用 / 冷卻、氣泡閒置 / 拖曳 / 彈回、續命三階段)外觀都不同, 不靠動畫才分得出
- P1 視覺權重跟著決策迫切度: 最迫切的「快過期」用全畫面唯一的紅色倒數環標出; 拖曳中的氣泡放大加影子壓在最上層; HUD 用暗底小面板退到角落
- P2 規則上存在的東西畫面上就存在: 網冷卻剩餘(扇形 + 數字)、彈回中不可抓(半透明)、續命「此刻有沒有效」(右上角小圈亮底 = 現在雙擊有效、暗底 = 還補不到、橫線 = 不能再補)、無效雙擊(小圈左右晃)都有獨立外觀
- P3 一個意義一種長相: 紅 = 損失、白勾 = 成功、虛線 = 暫時不可用, 遊戲內與說明頁共用; 說明頁的網、氣泡、命、結束畫面直接呼叫遊戲內畫法
- P4 關鍵區分至少兩條通道: 老闆已明言 prototype 不考慮色弱, 四色只靠色相 + 明度; 語意不同的狀態走兩條通道: 網可用(實線粗框 + 亮網格)vs 冷卻(虛線框 + 暗扇形 + 數字)、捕捉(白色勾)vs 錯網(紅色叉)
- P7 每個元素要掙得版面: 命用愛心不加「HP」字樣, 時間只帶「秒」; 網上不寫顏色名; 分數 / 連續只留兩字小標
- P13 事件要排隊: 本作沒有文字橫幅; 事件回饋全部貼在發生的網或氣泡上且 0.3~0.6 秒自己淡掉, 不會在同一處疊出多塊字
- P18 重要資訊不能只存在一瞬間: 扣命閃光之後空心愛心常駐; 分數與存活時間常駐 HUD, 並在結束畫面再列一次
- P19 資訊貼著物件: 冷卻數字畫在網中央、倒數與續命標示畫在氣泡本身; 錯網叉叉畫在那張網上
- P21 示意圖選分岔例子: 第 2 頁(錯網, 命少一格)與第 3 頁(同色進冷卻網被彈回, 命仍滿格)用同一個命列對照, 分開「錯網扣命」與「冷卻只彈回」; 第 4 頁第 2 顆(數字 7、小圈暗底 3)與第 3 顆(數字 2、小圈亮底 3)並排, 看得出「數字低於小圈才補得到」

## 物件表

所有函式簽章固定 `(ctx, state)`, 每個函式內部自行 save / restore。state 內沒寫預設值的欄位為必填。

| 物件 | 函式 | state 欄位 | 各狀態視覺差異 |
|---|---|---|---|
| 內圈外區域 | `drawBackground(ctx)` | 無 | 整面 bg 深色, 與內圈的亮一階地面對比, 不另畫 |
| 內圈 | `drawInnerRing(ctx, state)` | 無(state 可省略) | 固定: 半徑 200 的亮一階圓 + 3px 邊線 |
| 捕捉網(4 張, 每張呼叫一次) | `drawNet(ctx, state)` | `x, y`: 中心; `color`: 0~3; `cooldown`: 剩餘冷卻秒數, 0 = 可用(預設 0); `cooldownMax`: 冷卻總長(預設 2); `hot`: 拖曳中且指標在這張網判定半徑內時 true(預設 false); `flash`: `'catch'`/`'wrong'`/`'bounce'`/null, 剛發生的判定; `flashT`: 0→1 演出進度, 建議 0.5 秒跑完, ≥ 1 不畫 | 可用: 實線 5px 色框 + 亮網格 + 淡色底。冷卻中: 虛線色框(55% 透明)+ 暗網格; 網內扇形從 12 點順時針, 暗色 = 剩餘冷卻、色塊 = 已恢復, 中央白字剩餘秒數(小數一位)。hot: 外圈加 3px 白環(可用與冷卻都畫)。flash catch: 白環外擴 + 中央白勾; wrong: 紅環外擴 + 中央紅叉; bounce: 白色虛線環 |
| 氣泡 / 氣泡倒數 / 氣泡續命階段 | `drawBubble(ctx, state)` | `x, y`: 中心; `color`: 0~3; `timer`: 剩餘倒數秒(浮點); `renewCount`: 已續命次數 0/1/2; `mode`: `'idle'`/`'drag'`/`'return'`(預設 idle); `renewFx`: 續命成立回饋 1→0, 建議 0.4 秒(預設 0); `renewFailFx`: 無效雙擊回饋 1→0, 建議 0.3 秒(預設 0) | 本體: 色號實心圓 + 左上高光。倒數: 中央白字 = ceil(timer); 外圈倒數環長度 = timer / 12(各顆可直接比長短), ceil(timer) ≤ 3 時環變紅加粗。續命階段(右上角小圈): renewCount 0 顯示 7、1 顯示 3、2 顯示橫線(不能再續); 小圈亮白底 = 此刻 timer < 下次秒數(雙擊有效), 暗底 = 還補不到。mode drag: 放大 1.15 + 地面影子; return: 整顆 45% 透明(不可抓)。renewFx: 本體泛白 + 白環外擴; renewFailFx: 小圈左右晃 |
| HP / 存活時間 / 分數 / 連續數 | `drawHud(ctx, state)` | `hp`: 0~4; `hpMax`(預設 4); `time`: 存活秒數; `paused`: 暫停中 true; `score`; `combo`: 0 時不畫; `hpFlash`: 扣命回饋 1→0, 建議 0.6 秒(預設 0) | 左上: 愛心實心紅 = 剩餘、空心灰 = 已失去; hpFlash 時剛失去那格紅框放大 + 紅色半透明。時間 `xx.x 秒`; paused 時字變灰 + 右側暫停符號。右上: 分數大字右對齊, 連續數在下一列 |
| 暫停按鈕 | `drawPauseButton(ctx, state)` | `hover`(預設 false) | 圓角方塊 + 雙豎線, 下方小字「暫停」; hover 時底變亮、框變白 |
| 暫停選單 | `drawPauseMenu(ctx, state)` | `hover`: `'resume'`/`'restart'`/`'quit'`/`'help'`/null | 「開」= 呼叫本函式(全畫面暗罩 + 中央面板); 「關」= 不呼叫。繼續為主要按鈕(亮底); 重開、放棄為不可逆操作, 紅框紅字; 說明與前三個隔一段距離 |
| 標題畫面 | `drawTitleScreen(ctx, state)` | `hover`: `'start'`/`'help'`/`'device'`/null; `device`: null/`'mouse'`/`'touchpad'` | 自帶背景。遊戲名 + 四色氣泡 + 開始(亮底)/ 說明 / 輸入裝置; 已選過裝置時按鈕字為「輸入裝置: 滑鼠 / 觸控板」 |
| 輸入裝置選擇 | `drawInputSelect(ctx, state)` | `selected`: null(未選)/`'mouse'`/`'touchpad'`; `hover`: 同值或 null | 自帶背景。提問「你用什麼操作?」+ 兩張卡(滑鼠、觸控板圖示)。已選的卡 4px 白框 + 右上白勾; hover 底變亮 |
| 說明畫面(含示意圖) | `drawGuidePage(ctx, state)` | `page`: 1~5; `hover`: `'close'`/`'prev'`/`'next'`/null | 自帶背景。上方頁名與一句文字, 中間示意圖, 右上「關閉」、左下「上一頁」(第 1 頁不畫)、右下「下一頁」(第 5 頁不畫), 底部中央頁碼 |
| 結束畫面 | `drawEndScreen(ctx, state)` | `time`: 存活秒數; `score`; `hover`: `'retry'`/`'toTitle'`/null | 自帶背景。「結束」+ 存活時間(小數一位)與分數兩張卡 + 再玩一次(亮底)/ 回標題 |

### 按鈕與判定矩形(`Art.layout`)

點擊判定請直接讀 `Art.layout`, 與畫面保證一致(矩形皆為 `{x, y, w, h}`, x/y 為左上角):

- `layout.inner` = {x:640, y:360, r:200}; `layout.bubbleR` = 20; `layout.netR` = 60
- `layout.nets[i]` = {x, y, color}: 建議網色 上黃(0)、右綠(1)、下藍(2)、左紫(3)
- `layout.hudLeft` {20,20,240,80}; `layout.hudRight` {960,20,220,80}; `layout.pauseButton` {1206,26,48,48}(中心 1230,50)
- `layout.pauseMenu.resume / restart / quit / help`
- `layout.title.start / help / device`
- `layout.inputSelect.mouse / touchpad`
- `layout.end.retry / toTitle`
- `layout.guide.close / prev / next`

### 繪製層級(由下而上)

1. `drawBackground`
2. `drawInnerRing`
3. `drawNet` × 4
4. 閒置與彈回中的 `drawBubble`
5. 拖曳中的 `drawBubble`(永遠最上層的遊戲物件)
6. `drawHud`、`drawPauseButton`
7. `drawPauseMenu`(暫停時)
8. 標題 / 輸入裝置 / 說明 / 結束畫面各自整面重畫, 不需先畫遊戲畫面; 從暫停開說明時直接只畫 `drawGuidePage`
