# 捕泡手 美術規格(對應 spec v18 / decisions v26)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文字串在 file:// 下會變亂碼。
> art.js 以一般 `<script>` 載入, 產生全域 `window.Art`。全部 Canvas 2D 幾何, 無外部資源。

## v18 build 與上一版(v17)的差異, RD 要接的

本版是老闆指定的三關換主題(decisions v26), 只換「皮」; 函式名、參數、state 欄位、繪製層級、時長表、按鈕判定框全部沿用 v17。

| 類別 | 項目 | RD 要做什麼 |
|---|---|---|
| 換皮(畫法) | 第 1 首 夕照沙洲 → **林間**(明亮、綠意); 第 2 首 霓虹舞池 → **舞廳**(8-bit 迪斯可 + 粉洋紅玫瑰); 第 3 首 黑白警戒 → **魔龍**(黑暗奇幻) | 無。照舊傳 `level` |
| 換色票 | 三關 4 色、血量色、拍子色、背景 / 地面 / 網牆 / HUD 色全部重配(見第 2 節) | 若 RD 有寫死任何 v17 色碼(例如自己畫的除錯線), 改讀 `Art.palette[level]` |
| 色票(統一) | `danger` 三關統一 `#ff2b3d`(v17 三關各一個紅; 規格要求危險紅光三關一致) | 無 |
| 背景動態 | `drawBackground` 的 `beat` 現在三關都會用到(第 1 首草叢隨拍輕彈、第 2 首牆磚隨拍亮、第 3 首龍眼隨 2 小節週期變亮) | v17 已在傳 `time` / `beat`, 照舊; 沒傳就畫靜止版 |
| 說明頁 / 標題 / 結束畫面 | 依舊用第 1 首風格, 所以自動變成林間 | 無 |
| 新增 / 刪除函式 | 無 | — |
| state 欄位異動 | 無 | — |

## 1. 邏輯畫布尺寸

1280 × 720(`Art.canvas`)。內圈圓心 (640,360) 半徑 210; 網牆正八邊形每邊中點距圓心 300、頂點約 324.7; 地板環半徑 140。

**一組函式畫三套**: 幾乎每個 draw 函式的 state 都有 `level`(1 / 2 / 3, 缺省 1), 換關時 RD 只要把 `level` 換成新關即可整套換風格。

**4 色的辨識規則(沿用, node 驗算過)**: 同一關 4 色兩兩至少差 62°(三關最小差 80° / 62° / 66°), 無相鄰色相、無紅; 第二通道 = 明度, 4 色排成 4 個灰階階, 相鄰兩階至少差 35(第 1 首 86 / 126 / 165 / 210, 第 2 首 80 / 116 / 161 / 203, 第 3 首 72 / 114 / 159 / 196)。氣泡、光門條件、地板、沾上光環用同一個色碼。

**血量色的選色(node 驗算)**: 與同一關 4 色最小色相差 第 1 首 41° / 第 2 首 39° / 第 3 首 35°, 不與任何一色同色相; 離危險紅 ≥ 88°; 離拍子色 ≥ 75°。血量環只用在粗弧與血條, 不出現在任何小圓上, 不會被讀成第五色。

**拍子色的選色**: 與 4 色色相至少差 37°(第 2 首, 藍寶)/ 40°(第 3 首, 冰藍), 且明度都在 207 以上(比 4 色中最亮的還亮或接近、而且是淡色), 與同一顆氣泡上的沾上光環(屬性色、飽和)靠「淡 vs 飽和」再拉開一條。初稿第 2 首拍子色用螢光黃綠(83°, 與翡翠綠差 47°), 截圖上沾上光環(翡翠綠)與踩拍光暈(黃綠)疊在同一顆氣泡上被讀成同一團綠, 已改成淡水青, 原黃綠移去當血量色(只在血量環上, 不與回饋同框在一顆氣泡上)。

### 紅花與危險紅怎麼分開(第 2 首)

規格要求危險紅光三關一致, 所以不動危險紅, 改從花這一側讓開, 四條同時成立:
1. **色相**: 花用粉洋紅 #ec4f9c(331°)配亮粉 #ff9ccc 與酒紅陰影 #9c2a6a, 讀成「粉紅玫瑰」; 危險紅 #ff2b3d(355°)是純紅、飽和最高。花與 4 色也拉開(離紫晶 61°、離金 73°)
2. **位置**: 花只在畫面左下、右下角(八邊形距離 ≥ 400), 危險紅只出現在內圈內側(半徑 174~211)、血量環上的扣血段、氣泡上的紅叉與壽命環、左上血條框; 兩者在畫面上不相鄰
3. **動態**: 花完全靜止、不發光; 危險紅光以 1.3 秒週期脈動
4. **形狀語言**: 花是 8-bit 像素方塊拼的玫瑰 + 綠莖葉(背景裝飾的長相), 危險是柔光帶與細線

### 魔龍怎麼呈現而不干擾(第 3 首)

魔龍只在背景: 左右兩片龍翼(從八邊形外側展開)、右下角側面龍頭(閉口, 淡黃綠縱瞳)、左下龍尾, 全部是比背景只亮一階的暗紫剪影(#1c1430 + #3a2a56 邊線), **八邊形距離全部 ≥ 360**(光門外光最遠 344), 不進內圈、網牆、拍子提示與血量環所在的帶; 不與 HUD 矩形、暫停 / 靜音按鈕重疊。龍眼不用紅、不用拍子色; 亮度隨關內拍數每 8 拍(= 第 3 關輪轉週期)緩慢由暗到亮, 是背景唯一跟著關卡特色走的動態, 低不透明度。網牆另做成「鐵甲龍脊」(不亮的邊每節往外一根尖刺、頂點是往外彎的龍角), 尖刺只往外長, 不碰光門判定帶內緣。龍沒有任何規則、不可互動。

## 3. 形狀語言

可拿起的(氣泡)= 立體(放射漸層 + 高光 + 反光弧 + 常駐落影)、外緣是一圈壽命環且外緣 = 判定圓; 場景的(地板、內圈)= 平塗、無影、無高光; 會被「碰到」的東西(亮邊、氣泡外緣)畫面邊界 = 判定邊界, 外光只往外放。每關只換「皮」(明暗、質感、背景動態、網牆造型、色組、拍子提示造型、血量色), 不換「骨」。三套皮: 林間 = 柔圓、藤葉、年輪; 舞廳 = 8-bit 像素方塊、棋盤、金邊; 魔龍 = 尖角、鐵甲、寶石切面、法陣。

## 4. 理念落實

(經驗文件中狀態為「成立」的理念, 每條一句)

- P0 辨識度先於好看: 主題氛圍交給背景、地面紋理與網牆造型, 屬性 4 色只服從「色相不相鄰 + 明度分階」; 第 2 首老闆要的紅花讓到粉洋紅並鎖在角落, 第 3 首魔龍只做低對比剪影, 兩者都退在八邊形距離 360 以外。
- P1 視覺權重跟著決策迫切度: 亮著的光門(粗色帶 + 內緣白芯 + 外光)與操作中的氣泡最亮; 第 1 首背景改亮後, 在內圈周圍鋪一圈林蔭暗化(半徑 200~420), 讓光門、拍子提示所在的帶仍是暗底; 背景裝飾(樹、花、龍)都比遊戲物件低一階對比。
- P2 規則上存在的東西畫面上就存在: 光門判定加寬的 12 像素直接畫成亮邊的一部分(亮邊內緣 = 判定帶內緣, 換皮後 24 個光門重驗, 誤差 ≤ 1 像素); 氣泡外緣 = 判定圓(不放大、壽命環在外緣上)。
- P3 一本字典: 白 = 觸發 / 凍結; 灰虛線 = 已鎖定; 虛線 + 由中心長大 = 還沒生效; 危險紅三關同一個色碼 = 扣血 / 危險; 拍子色只代表拍子; 「深色墊 + 白形狀」= 形狀。主題裝飾不借用字典色: 花不用紅、龍眼不用紅也不用拍子色、舞廳牆磚的隨拍亮光用白與淡紫, 不用拍子色。
- P4 關鍵區分兩條通道: 4 色 = 色相 + 明度; 沾上 vs 踩拍(同一刻同一顆)= 顏色(飽和屬性色 / 淡拍子色)+ 動態(往外擴散 / 原地震動); 沾上 vs 已鎖定 = 顏色 + 線型 + 方向; 沾上(光門沒要)vs 其他三種 = 外形(方 / 三角)+ 動態(靜止); 血量環 vs 壽命環 = 尺度 + 顏色; 危險紅光 vs 拍子閃 = 位置 + 顏色 + 節奏; 紅花 vs 危險 = 色相 + 位置 + 動態 + 形狀。
- P7 每個元素掙得版面: 沿用 v17 的刪減(無踩拍拍點、無沾上標籤、歌曲進度無數字、血量環只有起點刻); 換皮時把畫面上所有字樣重掃一遍, 沒有新增任何字樣標籤。
- P9 以最混亂那刻驗收: 三關各一張滿場截圖(`acceptance-level1/2/3.png`, 8~9 顆氣泡、危險紅光中、拍子提示在拍點上、多種回饋同框)驗過: 色可辨、回饋找得到、血量環與拍子提示分得開; 第 2 首拍子色就是在這張截圖上被抓出來改掉的。
- P13 事件排隊: 同一顆同時沾色又賦形時第二個光環晚 0.08 秒、起點大一圈; 內圈邊緣由內到外分帶: 危險紅光(174~211)→ 血量環(214~228)→ 拍子提示(234~266, 第 3 首爪尖到 279), 三套拍子提示造型都守在這一帶(第 2 首方塊黑底內緣在 229)。
- P15 回饋強度和份量成正比: 每拍變化(本體內 2.5 像素邊 + 高光跳)< 出批(淡水紋)< 沾上(光門沒要)(靜止細線 + 暗墊)< 觸發(白細環 + 勾)< 沾上(光門要的)/ 踩拍第 1 級 < 第 2 級 < 第 3 級 < 整串; 換皮不動任何回饋的畫法與尺度, 只換拍子色。
- P17 進度圖形與數字分工: 血量環畫總量、無數字; 壽命環畫總剩餘比例; 歌曲進度做成播放頭而不是填滿條。
- P18 重要資訊不只一瞬間: 回血 / 扣血除了動作處回饋, 血量環與血條上都留 0.6 秒亮段。
- P19 資訊貼著物件: 血量環貼在內圈外緣; 踩拍、沾上、已鎖定回饋長在那顆氣泡本身; 光門條件在亮邊上; 跳位預告畫在目標那一邊; 輪轉預告畫在地板間隙。
- P21 示意圖選分岔例子: 說明頁 4 頁的圖不變(只隨第 1 首換成林間皮): 第 1 頁碰到光門那一格指標仍按著; 第 2 頁左右只差擦過 A 還是 B; 第 3 頁兩顆起點相同、只差有沒有被按住; 第 4 頁第 3 格有亮著要色 A 的光門、氣泡沒碰到它。

### 沾上(光門沒要)回饋(v17 設計, 本版沿用不變)

踩拍與整串用到的表現元素清單(判準 (c) 的禁用清單): 1 拍子專屬色 / 2 氣泡外緣外的放射漸層光暈 / 3 貼著外緣的同心圓輪廓 1~3 圈 / 4 輪廓原地震動 + 緩慢外移 / 5 發光外光(shadowBlur)/ 6 白色最內圈 / 7 氣泡大小的實心光團 / 8 輪廓或圓環往外擴散 / 9 白芯大範圍放射漸層閃光 / 10 20 根放射音浪條 / 11 輪廓下的深色描邊。新回饋 1~11 全部不用: 該形狀(方 / 三角)的深色平塗墊(黑 34%, 剪掉氣泡外緣半徑 21 以內)+ 2 像素白色實線形狀輪廓, 完全靜止, 0.06 秒淡入、停到 0.3 秒、0.3 秒線性淡出, 總長 0.6 秒; 透明度只看 `t`, 不看拍子。驗收畫面見 `acceptance-level2.png`(右上拖曳中的翡翠綠方塊)。

## 5. 物件表

共同: 每個函式 `(ctx, state)`, 自己 save / restore。`level` 缺省 1。`t` 若無特別說明是「該演出開始後經過的秒數」, 時長見第 7 節 `Art.timing`; 超過時長就不要再呼叫。全部隨暫停凍結(暫停時不推進 t / phase / beatPhase / time / beat)。

| 物件 | 函式 | state 欄位 | 狀態與視覺差異 |
|---|---|---|---|
