## 1. 邏輯畫布尺寸

1280 × 720(`Art.canvas`)。內圈圓心 (640,360) 半徑 210; 網牆正八邊形每邊中點距圓心 300、頂點約 324.7; 地板環半徑 140。

### 第 1、3 首 4 色重定(v21)

規格 v21: 第 1 關色 A 莓洋紅(328°)離危險紅(355°)只差 27°, 要拉到 ≥ 48°; 第 1、3 關四色重做「每色落在自己色名中心」驗收(第 3 關色 C 冰藍 200° 偏青)。做法照第 2 關(v19)與經驗文件 P3、P4: 每一色放在自己色名的正中, 兩色之間的色名區(綠與藍之間的青、紅與紫之間的洋紅)留空不分食; 色相 + 明度兩條通道各自成立。四色可用的色相範圍被危險紅(355° ± 48° = 307°~43° 不可用)夾成 43°~307°, 只放得下「黃 / 綠 / 藍 / 紫」四個色名, 所以第 1、3 關都改成這四個色名(第 2 關本來就是), 三關靠明度階排序與背景皮區分。

- 第 3 關色 D 從 277° 推到 288°: 新 C 在 225°, D 要讓出 ≥ 60°; 288° 仍是紫的中心, 離危險紅 67°

- 第 1 關葡萄紫與第 2 關紫紅(#c840e0, 291°)幾乎同色: 不同關不同框, 規格只要求同一關內四色分得開; 換關時帶過的那一顆照舊用 `paletteLevel` 畫舊關色

## 3. 形狀語言

可拿起的(氣泡)= 立體(放射漸層 + 高光 + 反光弧 + 常駐落影)、外緣一圈壽命環且外緣 = 判定圓; 場景的(地板、內圈)= 平塗、無影、無高光; 會被「碰到」的東西畫面邊界 = 判定邊界, 外光只往外放; 教學(v20)= 全畫面唯一「淺底深字」的泡泡(紙色底 + 深色字與描邊), 標示是紙色實線圈原地呼吸。UI(v21)= 圓角 8、內距與間距一律 8 的倍數; 按鈕三種長相: 一般(深底細框)/ 主按鈕(rim 色實心, 安全選項)/ 確定(深底粗 rim 框 + 斜紋, 會結束本局)。每關只換「皮」, 不換「骨」。三套皮: 林間 = 柔圓、藤葉、年輪; 舞廳 = 8-bit 像素方塊、棋盤、金邊; 魔龍 = 尖角、鐵甲、寶石切面、法陣。

## 4. 理念落實

(經驗文件中狀態為「成立」的理念, 每條一句)

- P0 辨識度先於好看: 教學泡泡不做成跟各關主題融合的面板, 而是三關都用同一種「淺底深字」, 一眼就知道「這是在教你」, 不會跟遊戲物件或其他提示混在一起; 三關只換泡泡的角(圓角 / 像素直角 / 切角)與紙色的色調。
- P1 視覺權重跟著決策迫切度走: 教學泡泡只有一行字、一顆; 遊戲不停, 所以泡泡預設在錨點上方、避開 HUD 與按鈕, 傳了 `litSlot` 時也避開亮著的光門(玩家當下要送去的地方), 不蓋被標示的物件(尾巴尖端停在標示圈外)。
- P2 規則上存在的東西畫面上就存在: 標示沿判定幾何畫 — 染色區 / 形狀區 / 氣泡圈在判定圓外 8 像素, 光門圈住整條判定帶(含往內 12 的加寬), 血量環內外兩側各一圈夾住軌; 教學講的「那個東西」就是規則上那個範圍。
- P3 一本字典(v21): 危險紅收回到只代表「血量危險 / 扣血」, 靜音中改用「壓暗 + 打叉 + 靜音中」, 確認面板的「確定」用 rim 色粗框斜紋, 兩者都不碰任何保留色(危險紅、拍子色、4 色、血量色、教學紙色)。四色: 第 1、3 關每色落在自己色名的中心(黃 / 綠 / 藍 / 紫), 不再有偏青的藍或貼著紅的洋紅。
- P3 一本字典(v20): 教學是新的一類, 所以給它字典裡沒人用過的長相: 淺紙色底(其他面板都是深底)、紙色實線圈原地呼吸(白色外擴環 = 觸發 / 沾上、白角框 = 換位 / 出場、虛線 + 長大 = 還沒生效、深底白勾 = 觸發成功, 全部避開); 完成用「紙色圓牌 + 深色勾」, 與觸發的「深色圓 + 白勾」黑白相反; 不用危險紅、拍子色、4 色與血量色。刪除說明標示中狀態後, 白色實心光圈不再出現。
- P4 關鍵區分兩條通道(v21): 四色 = 色相(兩兩 ≥ 63°)+ 明度 4 階(第 1 關階差 36 / 37 / 53、第 3 關 43 / 38 / 45), 兩條各自成立; 有聲 vs 靜音中 = 圖示形狀(聲波 / 叉)+ 明暗 + 字; 確定 vs 取消 = 填色(深底 vs rim 實心)+ 紋樣(斜紋)+ 框粗細。
- P4 關鍵區分兩條通道(v20): 教學泡泡 vs 換關提示(深底膠囊 + 拍子色框)= 明暗反轉 + 尾巴; 教學標示 vs 觸發 / 沾上的環 = 動態(持續原地呼吸 vs 一次外擴淡出)+ 線型(紙色實線帶深色外描, 3~5 粗); 教學完成勾 vs 觸發勾 = 明暗反轉 + 四角星散開; 其餘沿用 v19。
- P7 每個元素掙得版面: 確認面板只有問句、一行後果說明(重開 = 從第 1 關重新開始 / 放棄 = 直接看成績)與兩顆按鈕(v21); 泡泡只有一行字 + 必要時一個滑鼠圖示(只有「按住」需要); 沒有標題、頁碼、關閉鈕; 標示只在規格有寫「標示」的階段畫; 說明頁與形狀說明對話框整個刪除。
- P9 以最混亂那刻驗收: 開始畫面的靜音按鈕落在林間背景最亮的天空(bgTop #d9f7c8)上, 所以按鈕一律帶深色底板(hudPlate)而不是透明底(v21); 擺位在每一個錨點都跑同一套避讓(HUD、按鈕、亮著的光門、被標示物件、畫布邊), 不是只對階段表的預設位置調; 泡泡自帶深色描邊 + 落影, 壓在任何東西上都讀得到。
- P13 事件排隊: 同時只畫一顆泡泡(規格); 完成特效 0.8 秒播完, 泡泡在前 0.5 秒內縮小淡出(v21, `Art.timing.tutorialFade`), 下一個提示要等規格的 0.5 秒後才出現, 不會跟完成特效疊在一起。內圈周邊分帶沿用: 危險紅光 174~211 → 血量環 214~228 → 拍子提示 229~266; 血量環標示的兩圈落在 211 與 231, 夾住軌、不蓋環本身。
- P15 回饋強度和份量成正比: 教學完成特效(圓牌 17 + 8 顆小星散到 62)小於觸發以外的大回饋, 不搶踩拍與整串; 沿用 v18 分級。
- P17 進度圖形與數字分工: 沿用(血量環無數字); 教學不顯示進度或第幾步。
- P18 重要資訊不只一瞬間: 教學泡泡不會自己定時消失, 主線階段留到玩家做到為止; 條件式 12 秒沒做到才收起, 條件再成立會再出現。**張力**: 規格刪了說明頁, 教學完成後同一次開網頁不會再出現, 玩家沒有地方重看; 這是規格的決定, 美術不另補。
- P19 資訊貼著物件: 泡泡的尾巴尖端直接指到錨點(停在標示圈外緣), 錨點會動時泡泡每幀跟著走; 標示長在被講的那個物件本身的外緣。
- P21 示意圖選分岔例子: 教學沒有示意圖, 直接標在場上的實物上; 「染錯」那一段在玩家剛染錯的當下出現, 錨點是消失處、標示是亮著的光門, 這樣原因和結果會同時出現在畫面上。

### 沾上(光門沒要)回饋(v17 設計, 本版沿用不變)

踩拍與整串用到的表現元素清單(判準 (c) 的禁用清單): 1 拍子專屬色 / 2 氣泡外緣外的放射漸層光暈 / 3 貼著外緣的同心圓輪廓 1~3 圈 / 4 輪廓原地震動 + 緩慢外移 / 5 發光外光(shadowBlur)/ 6 白色最內圈 / 7 氣泡大小的實心光團 / 8 輪廓或圓環往外擴散 / 9 白芯大範圍放射漸層閃光 / 10 20 根放射音浪條 / 11 輪廓下的深色描邊。新回饋 1~11 全部不用: 該形狀的深色平塗墊 + 2 像素白色實線形狀輪廓, 完全靜止, 總長 0.6 秒; 透明度只看 `t`, 不看拍子。

### 新手教學提示 `drawTutorial(ctx, state)`
